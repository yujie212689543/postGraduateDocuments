## 一、采集命令（Windows PowerShell，逐条贴进去跑）

```powershell
nvidia-smi
Get-CimInstance Win32_VideoController | Select-Object Name, DriverVersion | Format-List
Get-CimInstance Win32_Processor | Select-Object Name, NumberOfCores, NumberOfLogicalProcessors | Format-List
"{0} GB RAM" -f [math]::Round((Get-CimInstance Win32_ComputerSystem).TotalPhysicalMemory/1GB,1)
Get-PSDrive -PSProvider FileSystem | Select-Object Name, @{n='FreeGB';e={[math]::Round($_.Free/1GB,1)}} | Format-Table
winver
wsl --status
nvidia-smi --query-gpu=name,memory.total,driver_version,compute_cap --format=csv
python -c "import sys; print(sys.version)"
```

要点：
- **显存看 `nvidia-smi`**，不要看 `AdapterRAM`（Windows 上超过 4GB 会显示错）。
- `compute_cap` 就是架构（30 系 = 8.6，40 系 = 8.9，50 系 = 12.0）。**50 系必须装 cu128 版 PyTorch**，40/30 系没这个坑。
- 若 `wsl --status` 报错，说明没装 WSL2，记"否"。

## 四、为什么需要这些（一句话）

异构机器最大的风险不是"跑不动"，而是**"跑得动但结果不可比"**——精度、驱动、批大小不同，同一方法的数字会漂。所以规则的第一条会是：**同一个方法的所有 run 固定在同一台机器上跑；跨机器的结果只做趋势对照，不做同条件比较。**
