# CISC7021 · 文本生成：温度（Temperature）与采样策略

---

## 0. 生成流程（30 秒）

1. 模型对下一个词算出一个**概率分布**，例如：`吃` 60% / `喝` 30% / `玩` 10%；
2. **采样策略**决定「怎么按这个分布挑一个词」；
3. **温度（Temperature）** 就是在挑词之前，先把分布「重新塑形」的旋钮。

---

## 1. 温度在数学上做了什么

Softmax 里除以一个温度 $T$：

$$P_T(w) = \frac{\exp(z_w / T)}{\sum_j \exp(z_j / T)}$$

- $z_w$：模型给词 $w$ 的原始分数（logit）；
- **$T = 1$**：分布保持原样；
- **$T < 1$**：所有分数差被**放大** → 分布变「尖」；
- **$T > 1$**：所有分数差被**缩小** → 分布变「平」。

---

## 2. 直观理解：低温 vs 高温

![[Pasted image 20260901211723.png]]

- **低温（如 0.2）→ 「死磕第一名」**
  最高的概率被抬得更高（`吃` 60% → ~90%），其他被压得更扁。
  **结果**：保守、稳定、可预测，但翻来覆去就那么几句，**缺多样性**。
  > 幻灯片原话：概率集中（concentrated），偏向最可能的类别。

- **高温（如 1.5）→ 「谁都敢试试」**
  最高的概率被拉低（`吃` 60% → ~30%），低概率被抬高（`玩` 10% → 25%）。
  **结果**：连概率最低的 `玩` 也有机会被选中 → 脑洞大开，**多样性爆棚**，但可能前言不搭后语。
  > 幻灯片原话：概率摊开（spread out），各类别更接近。

- **气温类比**：
  - $T \approx 0$：像**冰锥**，只剩一个尖 → 只选最准的；
  - $T = 1$：像**正常山丘** → 正常随机采样；
  - $T$ 很大：像**晒化的烂泥**，摊成一片 → 几乎乱选。

---

## 3. T → 0 = Greedy Decoding（贪心解码）

- 温度趋近 0 时，模型退化成「**永远只选当前概率最高的词**」的机器——这就是 **贪婪解码（Greedy Decoding）**。
- **问题**：一旦某一步选错，**后面步步错**（没有回头路）；而且**毫无创意**——写诗变打油诗，写代码变成重复模板。

> 所以「贪心」不等于「最好」：确定性带来稳定，却牺牲了多样性和纠错能力。

---

## 4. 实战调参指南

| 场景 | 推荐温度 | 原因 |
|---|---|---|
| 数学题、代码生成、事实问答 | **0.1 – 0.3** | 必须精确，不允许胡说八道 |
| 写小说、诗歌、头脑风暴 | **0.8 – 1.2** | 要创意和惊喜，又不至于太跑偏 |
| 纯搞笑、无厘头对话 | **> 1.5** | 放飞自我，乐趣无穷（接受前言不搭后语） |

---

## 5. 灵魂拷问：温度改变「知识」吗？

**不改变。** 温度不改模型学到的权重与知识，只改**「挑词时的冒险程度」**。

类比：同一位专家，让他**严谨作答**（低温）还是**大胆猜测**（高温），答案风格完全不同，但本事没变。

---

## 6. 搭配使用：Top-K 与 Top-p（补充）

纯靠高温会在**整张词表**里乱捞，可能捞到语法不通的词。常用做法是**先裁剪候选、再做温度采样**：

- **Top-K 采样**：只允许从概率最高的 **K 个词**里选，再重新归一化。→ 避免捞到「烂词」。
- **Top-p 采样（核采样 / Nucleus Sampling）**：动态选出「累计概率刚好超过 $p$」的一小撮词，再归一化采样。→ 候选数量随分布自信程度自动调整。

> 实践上通常 **温度 + Top-p / Top-K 一起调**：Top-p 管「候选范围」，温度管「在范围里有多大胆」。

---

## 7. 速查表

| 概念 | 一句话 |
|---|---|
| 温度 $T$ | 采样前缩放 logits 的旋钮 |
| $T<1$ | 分布变尖 → 保守、接近贪心 |
| $T>1$ | 分布变平 → 多样、可能乱 |
| $T\to0$ | 退化为 Greedy Decoding（只选最高概率） |
| 温度是否改知识 | 否，只改采样「胆量」 |
| Top-K / Top-p | 先限定候选范围，再按温度采样 |
