## 🔊 语音学 Phonetics

### 什么是语音学？
**Phonetics（语音学）**研究语音的**物理性质**——具体的发音方式、声音的产生机制。

💡 **记忆口诀**：Phonetics = **Phy**sical（物理的）

---

### 1. IPA 国际音标 (International Phonetic Alphabet)

#### 为什么需要 IPA？
- 英语拼写不规则：though, thought, rough, bough, through 发音完全不同
- IPA 实现**一对一映射**：一个符号 = 一个音

#### 核心原则
**Sound ↔ Symbol**（声音和符号一对一对应）

---

### 2. 辅音 (Consonants)

#### 发音部位 (Place of Articulation)

| 中文名 | 英文名 | 发音器官 | 例子 |
|--------|--------|----------|------|
| 双唇音 | **Bilabial** | 两片嘴唇 | [p] [b] [m] - **p**at, **b**at, **m**at |
| 唇齿音 | **Labiodental** | 下唇+上齿 | [f] [v] - **f**an, **v**an |
| 齿音 | **(Inter)dental** | 舌头在牙齿间 | [θ] [ð] - **th**ink, **th**is |
| 齿龈音 | **Alveolar** | 舌尖碰齿龈 | [t] [d] [s] [z] [n] [l] - **t**ap, **d**og, **s**ip, **z**ip |
| 后齿龈音 | **Post-alveolar** | 舌尖稍后 | [ʃ] [ʒ] - **sh**ip, plea**s**ure |
| 硬腭音 | **Palatal** | 舌面碰硬腭 | [j] - **y**es |
| 软腭音 | **Velar** | 舌根碰软腭 | [k] [g] [ŋ] - **k**it, **g**et, si**ng** |
| 声门音 | **Glottal** | 声带 | [h] - **h**at |

🎯 **记忆技巧**：从嘴唇到喉咙，从外往里记！
```
Bilabial → Labiodental → Dental → Alveolar → Post-alveolar → Palatal → Velar → Glottal
双唇       唇齿           齿      齿龈       后齿龈          硬腭      软腭      声门
```

---

#### 送气 (Aspiration)

**送气音**：发音时有明显气流喷出

##### 测试方法
把手放在嘴前或用纸条：
- **有气流** = 送气音 [pʰ] [tʰ] [kʰ]
- **无气流** = 不送气音 [p] [t] [k]

##### 英语规则
- **词首**的清塞音（p, t, k）**送气**：
  - **p**at [pʰæt]
  - **t**ap [tʰæp]
  - **k**it [kʰɪt]

- **s 后面**的清塞音**不送气**：
  - **sp**at [spæt]（不是 [spʰæt]）
  - **st**op [stɑp]
  - **sk**it [skɪt]

🔑 **考试重点**：能判断哪些词有送气音！

### 3. 元音 (Vowels)

#### 元音图 (Vowel Chart)

元音根据**舌头位置**分类：

```
        前 Front    中 Central    后 Back
高 High    i (bead)              u (food)
          ɪ (bid)               ʊ (foot)
          
中高        e (bait)             o (code)
          ɛ (bet)       ə       ɔ (caught)
                      (about)
          
低 Low      æ (bat)    ʌ (but)   ɑ (bot)
```

##### 三个维度
1. **高低 (Height)**：舌头抬得多高？
   - High（高）：[i] [u]
   - Mid（中）：[e] [o]
   - Low（低）：[æ] [ɑ]

2. **前后 (Backness)**：舌头在口腔的哪里？
   - Front（前）：[i] [e] [æ]
   - Central（中）：[ə] [ʌ]
   - Back（后）：[u] [o] [ɑ]

3. **圆唇 (Roundness)**：嘴唇是否圆起来？
   - Rounded：[u] [ʊ] [o] [ɔ]
   - Unrounded：[i] [ɪ] [e] [ɛ] [æ]

---

#### Tense vs Lax（紧元音 vs 松元音）

| Tense 紧元音 | Lax 松元音 | 对比 |
|-------------|------------|------|
| [i] | [ɪ] | b**ea**d vs b**i**d |
| [e] | [ɛ] | b**ai**t vs b**e**t |
| [u] | [ʊ] | f**oo**d vs f**oo**t |
| [o] | [ɔ] | c**o**de vs c**au**ght |

💡 **记忆法**：Tense = 更长、更紧张；Lax = 更短、更放松

---

### 4. 单元音 vs 双元音

#### Monophthong 单元音
**只有一个元音**，舌头位置不变
- 例子：[i] [u] [æ] [ɑ]
- bead [bid], food [fud], cat [kæt]

#### Diphthong 双元音
**两个元音组合**，舌头位置滑动（从一个元音滑向另一个）
- [aɪ] - b**i**te, f**i**ght（从 [a] 滑到 [ɪ]）
- [aʊ] - b**ou**t, h**ou**se（从 [a] 滑到 [ʊ]）
- [ɔɪ] - b**oy**, t**oy**（从 [ɔ] 滑到 [ɪ]）

🎯 **判断技巧**：
- 发音时嘴巴**移动** = 双元音
- 发音时嘴巴**不动** = 单元音

## 🎵 音系学 Phonology

### 什么是音系学？
**Phonology（音系学）**研究**语音模式和规则**——语言中哪些音可以组合、如何组合。

💡 **区别记忆**：
- Phonetics（语音学）= 物理层面，"这个音怎么发？"
- Phonology（音系学）= 规则层面，"这个音在语言中怎么用？"

---

### 1. 音位 vs 音位变体 (Phonemes vs. Allophones)

#### Phoneme 音位
- **抽象的、心理层面的**基本音素单位
- 用 **/ /** 表示
- 例：/p/ 是英语中的一个音位

#### Allophone 音位变体
- **具体的、物理层面的**实际发音
- 用 **[ ]** 表示
- 例：[pʰ]（送气）和 [p]（不送气）都是 /p/ 的音位变体

```
音位 /p/（抽象）
    ↓
[pʰ] 在词首 (pat)
[p]  在 s 后 (spat)
```

---

### 2. 最小对立对 (Minimal Pair)

#### 定义
**只有一个音不同**的两个词，且意思不同

#### 为什么重要？
证明两个音在该语言中是**不同的音位**

#### 例子

| 词1 | 词2 | 不同的音 | 证明 |
|-----|-----|---------|------|
| **p**at | **b**at | [p] vs [b] | /p/ 和 /b/ 是不同音位 |
| ba**d** | ba**g** | [d] vs [g] | /d/ 和 /g/ 是不同音位 |
| **s**ip | **z**ip | [s] vs [z] | /s/ 和 /z/ 是不同音位 |
| si**t** | si**ng** | [t] vs [ŋ] | /t/ 和 /ŋ/ 是不同音位 |

🔑 **考试技巧**：
- 必须**意思不同**！（sit vs seat ✓， site vs sight ✗ 意思相同）
- 只能**一个音**不同！（cat vs dog ✗ 太多不同）

---

### 3. 音节结构 (Syllable Structure)

#### 基本结构
```
     Syllable (音节)
         |
    ┌────┴────┐
  Onset      Rime (韵)
  (声母)      |
         ┌────┴────┐
      Nucleus   Coda
      (核心)   (韵尾)
```

#### 组成部分

| 部分 | 中文 | 位置 | 必须有吗？ | 例子 |
|------|------|------|-----------|------|
| **Onset** | 声母 | 开头的辅音 | ❌ 可选 | **str**eet |
| **Nucleus** | 核心 | 中间的元音 | ✅ 必须 | str**ee**t |
| **Coda** | 韵尾 | 结尾的辅音 | ❌ 可选 | stree**t** |
| **Rime** | 韵 | Nucleus + Coda | ✅ 必须有核心 | st**reet** |

---

#### 具体例子分析

**1. "cat" [kæt]**
```
   Syllable
      |
   ┌──┴──┐
Onset   Rime
  k    ┌─┴─┐
     Nucleus Coda
       æ     t
```

**2. "street" [strit]**
```
    Syllable
       |
   ┌───┴───┐
 Onset    Rime
  str    ┌─┴─┐
      Nucleus Coda
        i     t
```

**3. "eye" [aɪ]**（没有 Coda）
```
   Syllable
      |
   ┌──┴──┐
Onset   Rime
  ∅    ┌─┴─┐
     Nucleus Coda
       aɪ    ∅
```

**4. "at" [æt]**（没有 Onset）
```
   Syllable
      |
   ┌──┴──┐
Onset   Rime
  ∅    ┌─┴─┐
     Nucleus Coda
       æ     t
```

🎯 **记忆口诀**：
- **Nucleus（核心）= 必须有，通常是元音**
- **Onset 和 Coda = 可选的辅音**

---

### 4. 音系分析 (Phonological Analysis)

#### 核心步骤

**Step 1: 观察数据，列出环境**
找出某个音素在什么环境下出现

**Step 2: 寻找最小对立对**
确定是不同音位还是同一音位的变体

**Step 3: 找规律**
用自然类别（natural classes）概括

**Step 4: 写规则**
形式化地表达音系规则

---

#### 实例：英语复数 -s

##### 观察
- cab**s** [kæb**z**]
- cap**s** [kæp**s**]
- bus**es** [bʌs**əz**]

##### 规律
```
复数形式取决于词尾最后的音：

1. 浊音（非咝音） → 加 [z]
   cab-s [kæbz], dog-s [dɔgz]

2. 清音（非咝音） → 加 [s]
   cap-s [kæps], cat-s [kæts]

3. 咝音 [s, z, ʃ, ʒ, tʃ, dʒ] → 加 [əz]
   bus-es [bʌsəz], judge-s [dʒʌdʒəz]
```

##### 规则
```
基础形式：/-z/（默认）

规则1：咝音后插入 [ə]
  /z/ → [əz] / [+sibilant] __

规则2：清音后变清音
  /z/ → [s] / [-voice] __
```

💡 **记忆技巧**：说出来最自然、最省力的发音就是规则！

## 📐 形态学 Morphology

### 什么是形态学？
**Morphology（形态学）**研究**词的内部结构**——词是怎么由更小的意义单位组成的。

---

### 1. 语素 (Morpheme)

#### 定义
**最小的有意义单位**（minimal unit of meaning）

#### 判断方法
不能再拆分成更小的有意义部分

```
例子：
- "books" = 2 个语素
  ✓ book（书）+ s（复数）

- "impossible" = 3 个语素
  ✓ im-（否定）+ poss（能够）+ -ible（形容词后缀）
```

---

### 2. 自由语素 vs 粘附语素

#### Free Morpheme 自由语素
**可以独立存在**的语素

##### 例子
- **book**, **love**, **dog**, **run**
- 中文：**打**，**寄**，**书**

##### 类型
1. **Content words（实词）**：有具体意义
   - 名词、动词、形容词、副词
   - 例：dog, run, happy

2. **Function words（虚词）**：有语法功能
   - 冠词、介词、连词
   - 例：the, in, and

---

#### Bound Morpheme 粘附语素
**不能独立存在**，必须依附其他语素

##### 例子
- **-s**（复数）：book**s**
- **un-**（否定）：**un**happy
- **-ing**（进行时）：walk**ing**
- **-er**（比较级）：tall**er**

##### 中文例子
- **-化**：现代**化**，工业**化**
- **-子**：桌**子**，椅**子**
- **-们**：朋友**们**，孩子**们**

---

### 3. 派生语素 vs 屈折语素

这是**粘附语素**的两种类型：

#### Derivational Morpheme 派生语素
**改变词性或意义**，创造新词

##### 特点
✓ 可能改变词性
✓ 改变词根意义
✓ 可以有多个

##### 例子

| 词根 | + 派生语素 | 结果 | 变化 |
|------|-----------|------|------|
| happy (adj) | un-**happy** | unhappy (adj) | 意思相反 |
| happy (adj) | happi-**ness** | happiness (n) | 词性变化 |
| use (v) | use-**less** | useless (adj) | 词性变化 |
| teach (v) | teach-**er** | teacher (n) | 词性变化 |

---

#### Inflectional Morpheme 屈折语素
**只改变语法形式**，不改变词性或基本意义

##### 特点
✓ **不**改变词性
✓ **不**改变基本意义
✓ 只表达语法信息（时态、数、格等）
✓ **英语中都是后缀**

---

##### 英语的 8 个屈折语素

| 语素 | 功能 | 例子 |
|------|------|------|
| **-s** | 复数 | book → book**s** |
| **-'s** | 所有格 | John → John**'s** |
| **-s** | 第三人称单数 | walk → walk**s** (he walks) |
| **-ed** | 过去时 | walk → walk**ed** |
| **-ing** | 进行时 | walk → walk**ing** |
| **-en** | 过去分词 | eat → eat**en** |
| **-er** | 比较级 | tall → tall**er** |
| **-est** | 最高级 | tall → tall**est** |

🎯 **判断技巧**：
- 改变意思/词性 = **派生**（derivational）
- 只改变语法 = **屈折**（inflectional）

---

### 4. 词根、词干和词 (Roots, Stems, and Words)

#### Root 词根
最基本的**意义核心**，不能再拆分

```
例：love, ceive（在 receive 中）
```

#### Stem 词干
**词根 + 词缀**的中间形态，还可以继续添加词缀

```
love (root) → loveable (stem) → unloveable (word)
```

#### 形成过程

```
Input        Output         身份
─────────────────────────────────
love      →  loveable       词根 → 词干
loveable  →  unloveable     词干 → 词
```

---

### 5. 词缀类型 (Types of Affixes)

#### Prefix 前缀
加在**词根前面**

```
例：un-tie, re-write, dis-agree
```

#### Suffix 后缀
加在**词根后面**

```
例：kind-ness, teach-er, hope-ful
```

#### Infix 中缀（英语没有）
插入**词根中间**

```
例：菲律宾语 Bontoc
- fikas "strong" → f-um-ikas "to be strong"
- kilad "red" → k-um-ilad "to be red"
```

#### Circumfix 环缀
**同时**加在词根**前后**

```
例：Chickasaw（美国原住民语言）
- chokma "he is good" → ik-chokmo-o "he is not good"
```

---

### 6. 形态分析步骤

#### 例：unloveable

**Step 1: 识别语素**
```
un- + love + -able
```

**Step 2: 标注类型**
- **un-**：bound morpheme, prefix, derivational（否定意思）
- **love**：free morpheme, root
- **-able**：bound morpheme, suffix, derivational（变成形容词）

**Step 3: 画树状图**
```
        unloveable
           |
    ┌──────┴──────┐
   un-          loveable
                  |
              ┌───┴───┐
            love     -able
```

🔑 **考试重点**：
- 能判断每个部分是 free 还是 bound
- 能判断是 derivational 还是 inflectional
- 按正确顺序分析（屈折语素永远在最外层）

### 练习6：语素分析

**问题**：分析以下词有多少个语素？每个是什么？

1. **books**
2. **unhappiness**
3. **rebuild**
4. **dogs**

<details>
<summary>点击查看答案</summary>

1. **books** = **2个语素**
   - book (free morpheme)
   - -s (bound morpheme, inflectional - 复数)

2. **unhappiness** = **3个语素**
   - un- (bound morpheme, derivational - 否定前缀)
   - happy (free morpheme)
   - -ness (bound morpheme, derivational - 名词后缀)

3. **rebuild** = **2个语素**
   - re- (bound morpheme, derivational - "再次")
   - build (free morpheme)

4. **dogs** = **2个语素**
   - dog (free morpheme)
   - -s (bound morpheme, inflectional - 复数)
</details>

### 练习7：派生 vs 屈折

**问题**：判断下列划线部分是派生语素还是屈折语素

1. teach**er**
2. book**s**

## 🎯 快速记忆卡片

### Phonetics 语音学
```
💡 Phonetics = Physical 物理
- IPA: 一音一符号
- 辅音: 双唇 → 唇齿 → 齿 → 齿龈 → 后齿龈 → 硬腭 → 软腭 → 声门
- 送气: 词首送气，s后不送气
- 元音: 高/中/低 × 前/中/后 × 圆唇/不圆唇
- 单/双元音: 嘴动 = 双元音
```

### Phonology 音系学
```
💡 Phonology = Patterns 模式
- 音位 /p/（抽象）→ 音位变体 [pʰ][p]（具体）
- 最小对立对: 一音之差，意思不同
- 音节: Onset（可选）+ Nucleus（必须）+ Coda（可选）
- 规则: 观察 → 找规律 → 概括 → 写规则
```

### Morphology 形态学
```
💡 Morphology = Meaning units 意义单位
- 语素: 最小有意义单位
- Free 自由: 可独立（book, run）
- Bound 粘附: 需依附（-s, un-）
- Derivational 派生: 改变意思/词性
- Inflectional 屈折: 只改语法（英语8个，都是后缀）
```
