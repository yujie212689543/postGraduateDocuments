# 二、预选选修课
## 第一选择：

### CISC 7021 Applied Natural Language Processing

必选。

原因：

这是你的专业标签中最有就业价值的一门。

对应：

- NLP 工程
- 大模型应用
- RAG
- 企业 AI

## 第二选择：

### CISC 7026 Introduction to Deep Learning

如果它能计入你的选修学分，我非常建议。

原因：

你的必修：

- Python
- ML
- 数据库
- 可视化

已经有传统 Data Science 基础。

再加：

Deep Learning

你的技术闭环：

```
Python
 ↓
Data Science
 ↓
Machine Learning
 ↓
Deep Learning
 ↓
NLP
 ↓
LLM应用
```

非常完整。
