## 0. 实验范围（一句话）

GPT-2 XL + no-edit / ROME / MEMIT，数据集只用 ZsRE，每条序列 100 次连续编辑，2 条顺序，**正式编辑 run 共 4 组，全部在 Kaggle 跑**。

**为什么全部上 Kaggle**：本地唯一能跑编辑的机器（柯冠宇 12GB）实测空闲显存只有 9.8GB，而 ROME 默认配置就要约 10GB（fp32，`fp16: False`）、MEMIT 要 11GB。

## 1. 每台电脑：装什么、注意什么

### 顾渝杰｜ROG Strix G16（G614FP）

**配置**：RTX 5070 Laptop **8GB**（cc 12.0）｜Ryzen 9 9955HX 16 核 32 线程｜31.2GB｜C 279.8 / D 390.8 / F 377.8GB（E 仅 9.9GB）｜Win11 25H2｜无 WSL2

**装什么**
- Python **3.11 或 3.12**（现有的 3.14.5 对 PyTorch 偏新）
- PyTorch **cu128** 版：
  `pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu128`
- EasyEdit 及其依赖
- 只跑 **gpt2 / gpt2-medium**（小模型）做流程验证

**注意**
- **8GB 跑不了正式编辑**（ROME 需 10GB、MEMIT 需 11GB），别在这台机器上试
- 有 AMD 核显，跑 GPU 前先设 `CUDA_VISIBLE_DEVICES=0`，否则会落到核显上报错
- `HF_HOME` 设到 **D 盘或 F 盘**，**不要设到 E**（E 只剩 9.9GB）
- 这台是**代码主库**：所有代码只在这里改，另两台只拉取运行

### 柯冠宇｜Legion Y9000P IAX10H

**配置**：RTX 5070 Ti Laptop **12GB**（cc 12.0）｜Ultra 9 275HX 24 核｜31.4GB｜C 48.3 / D 128.6GB｜Win11 25H2｜无 WSL2｜Python 3.14.4 无 torch

**装什么**
- Python **3.11 或 3.12**
- PyTorch **cu128** 版（同上命令）
- EasyEdit 及其依赖

**注意**
- **实测空闲显存只有 9.8GB**（开机被占 1.9GB），ROME 临界、**MEMIT 会 OOM** → 本机只做验证，不出正式结果
- 跑之前先关掉浏览器、视频、微信等占显存的程序
- `HF_HOME` 设到 **D 盘**（C 盘只剩 48.3GB）
- **50 系显卡（cc 12.0）必须 cu128**：装成默认轮子会在**运行时**报 "no kernel image is available"，很容易误判成代码 bug

### 蔡小诚｜HUAWEI KLVC-WXX9（MateBook）

**配置**：MX350 **2GB**（cc **6.1**，驱动 442.50 / CUDA 10.2）｜i5-10210U 4 核｜15.8GB（焊死）｜C 95.6 / E 162.5GB｜Win11 25H2｜**无 Python、无 WSL2**

- `HF_HOME` 设到 **E 盘**
- 内存 15.8GB 且焊死不可扩展 → 不要读超大文件，用流式或抽样

## 2. Kaggle 怎么配置

1. **每人用自己的账号**（额度按账号算：1 个 = 30 小时/周，3 个 = 90 小时/周）
2. Notebook 选 **GPU T4 ×2（16GB）**，并打开右侧 **Internet** 开关（否则 pip 装不了东西）
3. **用 Kaggle 自带的 PyTorch，不要装 cu128**（T4 是 cc 7.5，自带版本已支持）
4. 依赖用 **`requirements-kaggle.txt`**（不指定 torch 索引）；transformers 等版本必须与本地一致
5. **别每次重下 gpt2-xl**（约 6GB）：第一次下完打包成 **Kaggle Dataset**，之后挂载复用
6. 结果写进 **`/kaggle/working`** 后**必须点 Save Version**，否则会话结束就没了
7. **一次会话约 9–12 小时上限**，一个 session 只跑一个 run
8. **调试不上 Kaggle**（放本地 12GB 机器或 gpt2 小模型），额度只留给正式 run

**环境文件分两份**（同一个文件会打架）
- `requirements-local.txt`：给顾渝杰、柯冠宇（cu128）
- `requirements-kaggle.txt`：给 Kaggle（用自带 torch）
- 蔡小诚不需要 torch

## 3. run 分配

正式编辑 run 共 4 组，全部在 Kaggle。

| run | Kaggle 账号 | 预计耗时 |
|---|---|---|
| no-edit 基线评测 | 任意 | 几分钟 |
| ROME × 顺序 1 | 账号 1（蔡小诚） | 约 0.5–1.5 h |
| ROME × 顺序 2 | 账号 1（蔡小诚） | 约 0.5–1.5 h |
| MEMIT × 顺序 1 | 账号 2（柯冠宇） | 约 0.5–1.5 h |
| MEMIT × 顺序 2 | 账号 2（柯冠宇） | 约 0.5–1.5 h |
| AlphaEdit 尝试（可选） | 账号 3（顾渝杰） | 视情况 |

**一条硬规则**：**同一个方法的全部 run 必须在同一台机器/同一平台上跑完。**
`ROME 顺序 1 在本地、顺序 2 在 Kaggle` 这种做法绝不允许——两个顺序的差异里会混进机器差异，结论就废了。
