## 先背这 15 句

1. **Phonetics** 研究声音本身；**Phonology** 研究声音模式。
2. 辅音用 **Voicing + Place + Manner（VPM）**。
3. 元音用 **height + front/back + rounding**。
4. **Minimal pair** 必须只差一个音、同位置、意义不同。
5. 有 minimal pair -> 不同 phonemes；互补分布 + 相似 -> 同一 phoneme 的 allophones。
6. 音节必须有 **nucleus**；`rime = nucleus + coda`。
7. **Morpheme** 是最小意义单位；**inflection 改形式，derivation 造新词**。
8. English 有 **8 个屈折语素**，全是后缀。
9. **Grammatical != meaningful**。
10. 结构歧义先问：**PP 修饰动作还是名词？**
11. X-bar 先找 **head**，再找 **complement**，最后加 **adjunct**。
12. **Entailment** 是单向的：A 真 -> B 必真。
13. **Thematic role** 不等于 subject/object。
14. **Wug test** 证明 rule generalization。
15. **Broca** 费力缺语法；**Wernicke** 流利但内容乱。

## 1. Phonetics（语音学）

**三个判断**：

- Vowel：气流相对通畅；Consonant：有 closure / constriction。
- **Voicing**：声带振不振。
- **Place**：哪里挡；**Manner**：怎么挡。

**最常考**：

| 音 | 描述 |
|---|---|
| `[p]` | voiceless bilabial stop |
| `[b]` | voiced bilabial stop |
| `[ʃ]` | voiceless post-alveolar fricative |
| `[tʃ]` | voiceless post-alveolar affricate |
| `[ŋ]` | velar nasal |
| `[w]` | labial-velar glide |

**送气**：

- `pat [pʰæt]`：词首送气。
- `spin [spɪn]`：`/s/` 后不送气。
- English `/p-b/` 主要靠 **voicing**；Mandarin 靠 **aspiration**。

**元音**：

- 圆唇只有 `/u ʊ o ɔ/`。
- tense-lax：`i-ɪ`、`e-ɛ`、`u-ʊ`、`o-ɔ`。
- diphthongs：`/aɪ aʊ ɔɪ/`。

## 2. Phonology（音系学）

**一步判断**：

```text
有 minimal pair?
  是 -> 不同 phonemes
  否 -> 互补分布 + 语音相似 -> 同一 phoneme 的 allophones
```

- `/ /` = phoneme；`[ ]` = allophone。
- `ship/sheep`：不同 phonemes。
- English `[p]/[pʰ]`：同一个 `/p/`。
- `[h]/[ŋ]`：互补但不相似 -> 不同 phonemes。

**音节**：

```text
σ = Onset + Rime
Rime = Nucleus + Coda
Nucleus required
```

**四条规则**：

| 现象 | 规则 |
|---|---|
| 音更像 | assimilation |
| 音更不像 | dissimilation |
| 多一个音 | insertion |
| 少一个音 | deletion |

**复数**：

```text
voiced non-sibilant -> [z]
voiceless non-sibilant -> [s]
sibilant -> [əz]
```

## 3. Morphology（形态学）

**词单位**：

- **Morpheme**：最小意义单位。
- **Free**：能单独说，如 `dog`；**bound**：不能，如 `un-`。
- **Root**：构词基础；**stem**：已加词缀、还能继续加词缀。

**English 8 个屈折语素**：

```text
-s 3sg   -ed   -ing   -en
-s plural   -'s   -er   -est
```

全部是 **suffix**。

| | Inflection | Derivation |
|---|---|---|
| 功能 | grammar | 造新词 |
| 词性 | 不变 | 可能变 |
| 例子 | `tall-er` | `teach-er` |

**分析题**：先找重复词根，再找重复词缀。

例：`no- = my`、`mo- = your`、`i- = his`、`-mes = plural`。

## 4. Syntax（句法学）

**先分清**：

- **Grammatical**：句法规则允许。
- **Meaningful**：意义讲得通。

`Colorless green ideas sleep furiously` = grammatical but semantically anomalous.

**Constituent 三测**：

```text
Stand alone / Pronoun replacement / Move as unit
```

**两种歧义**：

- Lexical：一个词多义，如 `duck`。
- Structural：同一词串、两棵树，如 `Sue saw the man with the telescope`。

**基础规则**：

```text
S -> NP VP
NP -> Det N
VP -> V NP
PP -> P NP
```

```text
S
├── NP
│   ├── Det: the
│   └── N: child
└── VP
    ├── V: found
    └── NP
        ├── Det: a
        └── N: puppy
```

![[AHGC7315-Syntax-P37.png]]

**X-bar**：

```text
XP
├── Specifier
└── X'
    ├── X'
    │   ├── X = Head
    │   └── Complement
    └── Adjunct
```

![[AHGC7315-Syntax-P50.png]]

- **Complement**：删掉后 head 意义不完整，如 `found the child`。
- **Adjunct**：删掉后仍完整，如 `found the child in the park` 的 `in the park`。
- **Head-initial**：English / Mandarin；**head-final**：Japanese / Korean。
- Yes-no question 移助动词；无助动词用 do-support。
- Agreement 找真正 subject，不找最近 noun。

## 5. Semantics（语义学）

**三种关系**：

| 关系 | 判断 |
|---|---|
| **Entailment** | A 真 -> B 必真 |
| **Paraphrase** | 双向蕴含 |
| **Contradiction** | A 真 -> B 必假 |

```text
Jack swims beautifully -> Jack swims
但反过来不能推
```

**词汇关系**：

| 词 | 区别 |
|---|---|
| Synonym | 同义 |
| Antonym | 反义 |
| Homonym | 同拼同音异义：`bark` |
| Homophone | 同音：`bear/bare` |
| Heteronym | 同拼异音：`dove/dove` |
| Polysemy | 多个相关意义 |

**Reference vs Sense**：

- Reference 指现实对象。
- Sense 是表达本身携带的意义。

**Thematic roles**：

| Role | 意思 |
|---|---|
| Agent | 有意发起者 |
| Theme | 最直接受影响者 |
| Goal / Source | 终点 / 来源 |
| Location | 地点 |
| Instrument | 工具 |
| Experiencer | 感受者 |

```text
The dog bit the stick.       Agent / Theme
The key opened the door.     Instrument / Theme
Many people fear snakes.     Experiencer
```

## 6. Language Acquisition（语言习得）

```text
输入有限、杂乱 -> 孩子仍能产生新句子
-> Innateness hypothesis / Universal Grammar
```

- **Poverty of stimulus**：输入不足以解释最终语法能力。
- **Wug test**：没听过 `wug`，仍说 `wugs /wʌgz/` -> 规则泛化。
- **L2 transfer**：把 L1 规则带进 L2。
- **Fossilization**：错误固定。
- L2 critical period 是 **trend**，精确年龄 disputed。

## 7. Psycholinguistics（心理语言学）

- **Semantic priming**：`tape -> glue`
- **Phonological priming**：`tape -> grape`
- **Morphological priming**：`tape -> taped`
- **Stroop / negative priming**：压制干扰项
- **Garden path**：temporary ambiguity -> reanalysis
- `The horse [that was raced past the barn] fell`

| Broca | Wernicke |
|---|---|
| 费力、slow、agrammatical | 流利但内容乱 |
| 缺功能词和词尾 | comprehension / naming 有问题 |

- L1 critical period 错过后：词汇仍可学，完整 grammar 很难。
