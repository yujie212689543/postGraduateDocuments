# AHGC7315 考前复习 09｜Language Acquisition（语言习得）

> **考试范围**：innateness hypothesis、wug test、critical period hypothesis for L2。
>
> **一句话总览**：孩子学 L1 很快、能说出没听过的新句子；课件用 **innateness / Universal Grammar** 与 **rule generalization** 解释，L2 则通常受年龄与 L1 transfer 影响。

## 1. Innateness hypothesis（先天性假说）★

### 先用最白话的方式理解

孩子不是把大人说过的每一句话录下来再复读。否则他不可能说出从未听过的新句子，也不可能知道哪些句子不自然。课件的解释是：人类天生有一套“学语言的底层模板”，叫 **Universal Grammar（UG，普遍语法）**；孩子主要学的是自己语言的具体设定。

| 术语 | 考试可写的定义 | 记忆法 |
|---|---|---|
| **Innateness hypothesis（先天性假说）** | humans are already equipped with a grammar book, **Universal Grammar** | 出厂自带“语法框架” |
| **Universal Grammar / UG（普遍语法）** | 使儿童能从有限输入获得语法知识的 innate capacity | 所有孩子共用的底层能力 |
| **Poverty of the stimulus（刺激贫乏）** | available input is insufficient to explain children’s rich grammatical knowledge | 输入不完美，输出却超出输入 |

![[AHGC7315-Acquisition-P8.png]]

### 为什么说 input 不够？

课件的两条 evidence：

1. **Positive evidence only（只有正面证据）**：父母通常改内容而不是系统地告诉孩子“这个语法不对”。
2. **Degenerate input（退化/不完美输入）**：儿童会听到口误、停顿、假起句、不完整或不合语法的话。

但儿童能做 **generalization（泛化）**，而且不会随意犯违反 **structural dependency（结构依赖）** 的错误。结论不是“完全不需要输入”，而是输入本身不足以解释习得的速度、统一性和创造性。

## 2. Wug test（Wug 测试）：孩子懂规则，不是背单词 ★★★

### 核心题型

研究者给孩子一个他从未见过的假词：一只叫 **wug** 的动物。再给第二只，问：`There are two ____.`

若孩子答 **wugs** `/wʌgz/`，就说明他并不是记住 dog → dogs，而是会把 English plural rule 用到从未听过的词上。

![[AHGC7315-Acquisition-P27.png]]

| 现象 | 代表什么 |
|---|---|
| children have never heard *wug/wugs* | 不可能靠死背答案 |
| nevertheless produce `/wʌgz/` | 他们 learned the plural rule and can generalize |
| choose `[s] / [z] / [əz]` correctly | 还显示理解 phonological natural classes（音系自然类） |

**你要会套用的英语复数规则：**

| 词尾 | 复数 | 例子 |
|---|---|---|
| voiced non-sibilant（浊、非咝音） | `[z]` | wug → wugs `/wʌgz/` |
| voiceless non-sibilant（清、非咝音） | `[s]` | wup → wups |
| sibilant（咝音） | `[əz]` | wush → wushes |

### Mandarin 版本

课件用 **Tone 3 sandhi（三声变调）**说明同一思路：`T3 + T3 → T2 + T3`，如 `hao3 hao3 → hao2 hao3`。若受试者能把规则用于新情境，就显示其掌握的是 rule，而不只是背过 `好好` 这个词。

## 3. 儿童语言习得的简表（理解用）

| 大约年龄 | 阶段 | 关键现象 |
|---|---|---|
| 出生–1 岁 | speech-sound acquisition | 初生婴儿能区分世界语言的各种 speech sounds；后来专注 native-language sounds |
| 约 6 个月 | babbling | 开始 babble；逐渐丧失对非母语对立的敏感性 |
| 约 9 个月 | repeated CV babbling | `mama, gaga, dada` |
| 约 12 个月 | first word / holophrastic stage | 一个词可表达整句意思 |
| 2;6–3;6 | language explosion | 快速发展；到约 3 岁能稳定使用 function morphemes 和 complex structures |
| 3;6 后 | syntax | 能产生 wh-questions、relative pronouns |
| 约 4 岁后 | adult-like competence | 习得大部分成人句法能力 |

![[AHGC7315-Acquisition-P35.png]]

这张表通常不是老师列出的最主要考点；把它当作帮助你理解为什么“儿童习得”特殊的背景即可。

## 4. Second Language（L2）与 critical period（关键期）★★

| 概念 | 课件要点 |
|---|---|
| **L1（第一语言）** | native language；先习得的语言 |
| **L2（第二语言）** | acquired L1 之后学习的任何语言 |
| **Fundamental difference hypothesis（根本差异假说）** | L2 learning 和 L1 learning 是不同 process；因为 L2 learner 已有 L1 |
| **L1 transfer（第一语言迁移）** | 学 L2 时会把 L1 的 phonological/syntactic/morphological rules 带过去 |
| **fossilization（石化）** | 成人 L2 errors 可能固定下来 |

课件例：Mandarin speaker 学 English 可能 `/θ/ → [s]`；English speaker 学 Mandarin 可能把 `/y/` 读成 `/iu/`。

### Critical period hypothesis for L2（L2 关键期假说）

**要背的精确立场：**它是 **tendency / trend（趋势）**，不是硬性绝对界线。

- Children usually learn L2 faster and more easily obtain native-like fluency.
- 年龄越小开始，通常效果越好。
- 关键年龄具体是多少仍 **controversial / not defined**；课件说假说范围约 2–13/14，且有表现出色的成人学习者反例。
- 晚学者可以 grammar 很好，但仍可能有 foreign accent。
