# AHGC7315 Final Exam｜09 Language Acquisition（语言习得）

> **优先级：次于 Syntax / Semantics。** 老师明确提示 Final Exam 重点考句法学和语义学；本章先保住现有复习范围里的高频概念，不必平均用力。
>
> **现有复习范围：** innateness hypothesis、wug test、L2 critical period hypothesis。
>
> **一句话总览：** 孩子听到的语言输入有限、还会听到错误和半截话，却能在几年内掌握复杂语法，并能把规则用到从未听过的词上。天生论用 **Universal Grammar（UG）** 解释这种能力；成人学 L2 则受已有 L1、年龄与迁移影响。
>
> **来源：** `Language-Acquisition.pdf`，P1–P39。

## 1. Innateness hypothesis（先天性假说）★★

### 1.1 先别背术语，先看矛盾

五岁孩子已经会大部分 grammar，但他们：

- 没有正式上过语法课；
- 父母通常不会系统教规则；
- 听到的输入里有口误、停顿、假起句；
- 却能说出大量以前没听过的新句子。

课件用 **poverty of the stimulus（刺激贫乏）** 概括：

```text
儿童获得语言时的输入，不足以单独解释他们最终掌握的语言知识。
```

| 术语 | 考试定义 | 人话记忆 |
|---|---|---|
| **Innateness hypothesis（先天性假说）** | humans are equipped with **Universal Grammar** | 人一出生就带着“语言学习底层模板” |
| **Universal Grammar / UG（普遍语法）** | 帮助儿童从有限输入获得语法的 innate capacity | 孩子只需学习自己语言的具体设置 |
| **Poverty of the stimulus（刺激贫乏）** | input 不足以解释儿童丰富的语法知识 | 原料少，成品却远超原料 |

![[AHGC7315-Acquisition-P8.png]]

### 1.2 两条证据

#### Positive evidence only（只有正面证据）

父母通常纠正孩子说的“内容”，很少系统纠正语法：

```text
Child: We goed to the park.
Parent: Yes, we went to the park.
```

家长更可能回应“你去了公园”这件事，而不是解释 `goed` 为什么错。

#### Degenerate input（不完美的输入）

真实输入充满：

- slips of the tongue（口误）；
- false starts（话说一半又重新开始）；
- ungrammatical sentences（不合语法的话）；
- incomplete sentences（不完整句）。

孩子仍能从这种环境里抽出可靠规则。

### 1.3 但重点不是“输入完全没用”

正确理解是：

```text
语言习得 = 天生的 UG 能力 + 环境中的语言输入
```

不是“孩子完全不用听别人说话”。

## 2. Structural dependency（结构依赖）：孩子不会犯的错

课件用 Ninja Turtle 例子说明：儿童即使听到复杂句，也不会把 pronoun 错误地指向“距离最近的人”，而会遵守句子的抽象结构。

```text
While he was dancing, the Ninja Turtle ate pizza.
      ↑                          ↑
      he 可指 Ninja Turtle
```

```text
He ate pizza while the Ninja Turtle was dancing.
↑
这里通常不把 he 反向指到后面的 Ninja Turtle
```

这说明儿童学的不是“左边最近的人就是 antecedent”，而是：

```text
structural dependency（结构依赖）
```

同样的思想会在 Psycholinguistics 的主谓一致、Syntax 的树结构中再次出现。

## 3. Wug test（Wug 测试）★★★

### 3.1 实验到底做什么？

实验者给儿童看一只从没见过的假动物：

```text
This is a wug.
```

再给儿童看两只：

```text
There are two ______.
```

如果儿童回答：

```text
wugs /wʌgz/
```

就说明他们不是从 memory 里取出 `dog → dogs` 这个固定答案，而是把 English plural rule 用到了一个全新的词上。

### 3.2 它证明了两件事

1. 儿童掌握的是 **rule（规则）**，不是模仿；
2. 他们能 **generalize（泛化）**，把规则用于没听过的词。

![[AHGC7315-Acquisition-P27.png]]

### 3.3 选 `[s] / [z] / [əz]` 还说明什么？

English 复数不是死加一个音：

| 词尾类型 | plural allomorph | 例子 |
|---|---|---|
| voiced non-sibilant（浊、非咝音） | `[z]` | wug → wugs `/wʌgz/` |
| voiceless non-sibilant（清、非咝音） | `[s]` | wup → wups |
| sibilant（咝音） | `[əz]` | wush → wushes |

儿童选对 allomorph，说明他们掌握的是 **natural classes of phonemes（音位自然类）**，不是背过完整发音。

### 3.4 Mandarin 的“Wug-like test”

普通话用 **Tone 3 sandhi（三声变调）**：

```text
T3 + T3 → T2 + T3
hao3 hao3 → hao2 hao3
```

实验用熟悉词的某个字测试：

```text
老師 /lao3 shi1/ 的第一个字是？
→ lao3

現在說「老師的老」：
→ lao2 shi1 de lao3
```

如果受试者能把变调规则用到新的组合里，说明掌握的是规则而非整词记忆。

## 4. 儿童语言习得的时间线

这张表用于理解“为什么五岁儿童已经很强”，不是本章最高优先级。

| 大约年龄 | 阶段 | 关键现象 |
|---|---|---|
| 出生–1 岁 | speech-sound acquisition | 婴儿最初能区分世界各种 speech sounds |
| 约 6 个月 | babbling | 开始咿呀发声，逐渐失去对非母语对立的敏感 |
| 约 9 个月 | repeated CV babbling | `mama, gaga, dada` |
| 约 12 个月 | first word / holophrastic | 一个词可以表达一整句意思 |
| 1 岁多 | word meaning | 可能 **overextend**：把 `cat` 用于所有毛茸茸四足动物 |
| 2;6–3;6 | language explosion | 快速使用 function morphemes 和复杂结构 |
| 3;6 后 | syntax | wh-questions、relative pronouns |
| 4 岁后 | adult-like competence | 已获得大部分成人句法能力 |

![[AHGC7315-Acquisition-P35.png]]

### Overextension（词义过度扩展）

儿童可能把 `cat` 用来指所有毛茸茸、四足、相似形状的动物。课件强调 overextension 通常依据：

- shape；
- size；
- texture；

但通常**不是 color**。

## 5. Second Language Acquisition（第二语言习得）

### 5.1 L1、L2 与根本差异

| 概念 | 意思 |
|---|---|
| **L1（第一语言）** | native language；先习得的语言 |
| **L2（第二语言）** | 习得 L1 之后学习的任何语言 |
| **Fundamental difference hypothesis（根本差异假说）** | L2 learning 与 L1 acquisition 是不同 process |

关键差异是：学 L2 时，学习者脑中已经有完整 L1。

### 5.2 Fossilization 与 L1 transfer

**Fossilization（石化）**：成人的 L2 errors 可能长期固定下来。

**L1 transfer（第一语言迁移）**：学习者把 L1 的规则带到 L2。

课件例子：

| 学习者 | 可能迁移 | 表现 |
|---|---|---|
| Mandarin speaker 学 English | L1 phonology | `/θ/ → [s]` |
| English speaker 学 Mandarin | L1 phonology | `/y/ → /iu/` |

迁移不只可发生在 phonology，也可见于 syntax、morphology。

## 6. L2 Critical Period Hypothesis（L2 关键期假说）★★

### 6.1 最准确的说法

```text
年龄越大，达到 native-like fluency 的难度通常越高。
```

但这不是绝对开关。

课件明确说：

- critical age **controversial / not defined**；
- 不同假说把年龄范围放在约 **2–13 / 14 岁**；
- 仍不断发现成功的成人 L2 learners。

因此本章应按以下词答：

| 不能写成 | 应该写成 |
|---|---|
| “过了 X 岁一定学不会” | “是一种 **tendency / trend**” |
| “成人不能达到好语法” | “晚学者可以有很好的 grammar，但可能保留 foreign accent” |
| “所有人在同一年龄失去能力” | “exact critical age 仍有争议” |

![[AHGC7315-Acquisition-P38.png]]

### 6.2 “Use it or lose it”

课件用神经可塑性解释趋势：儿童时期参与 L1 learning 的多余 neural circuitry 会随年龄被精简。可把它理解为：

```text
越早使用相关语言回路，越容易保留那种学习能力。
```

但记住课件没有把它说成绝对、统一的硬截止年龄。
