## 1. Psycholinguistics 的人话定义

**Psycholinguistics（心理语言学）**研究语言的心理层面：

```text
大脑怎样产生语言？
听到声音后怎样找词、组句、理解意思？
语言知识怎样与 mental processes 连接？
```

它介于语言学与心理学之间：既关心 grammar，也关心 grammar 在真实大脑中怎样被实时使用。

## 2. Comprehension（理解）：Bottom-up 与 Top-down

### 2.1 Bottom-up processing（自下而上）

从最小的声音细节，一层层往上组合：

```text
Acoustic signal
→ phonemes
→ morphemes
→ words / phrases
→ semantic interpretation
```

课件用：

```text
The dog chased the boy.
```

展示 listener 怎样逐步把 `The`、`dog`、`chased` 等词建成 NP、VP、S。

**人话记忆：先听到零件，再把零件装成整句。**

### 2.2 Top-down processing（自上而下）

从语境、预期和较大的结构开始，预测接下来会出现什么：

```text
Context → semantics → syntax
→ expectations about acoustic signal
```

课件用 **shadowing task（影子跟读任务）** 支持：listener 会根据已经听到的内容预测后续。

**人话记忆：先知道“大概在说什么”，再帮助辨认声音。**

### 2.3 实际理解通常二者同时进行

| 方向 | 起点 | 帮助 |
|---|---|---|
| Bottom-up | 声音细节 | 不遗漏实际输入 |
| Top-down | 语境和预测 | 处理噪声、歧义和快速语音 |

听力不好时，不一定是“听不到全部声音”，也可能是 top-down knowledge 不足。

## 3. Lexical access（词汇通达）

### 3.1 三个词

| 术语 | 人话解释 |
|---|---|
| **Mental lexicon（心理词库）** | 脑中的“字典” |
| **Lexical retrieval（词汇提取）** | 从脑内字典取一个词 |
| **Lexical decision（词汇判断）** | 快速判断一串字母是否是真词 |

在 lexical decision task 中，研究者记录 **Response Time / RT（反应时间）**：

```text
看到词/非词 → 按“是/否” → 记录按按钮用了多久
```

RT 越长，通常表示 lexical retrieval 越难或越慢。

### 3.2 哪类词反应更慢？

课件给出三种情况：

1. **低频词**比高频词慢：`cad` > `car`；
2. **可能的非词**比不可能的非词慢：`plim` > `tlat`；
3. phonological neighborhood 更大、更密集时更慢。

为什么？可用“竞争者”理解：

```text
pad, pot, pit, pet, put, paid, pod...
发音/拼写相近的候选越多，辨认目标词的干扰越大。
```

## 4. Priming effect（启动效应）★★★

### 4.1 一句人话

先看到一个相关词，会把目标词提前“热身”或 **pre-activate（预激活）**，于是目标词更快被认出。

```text
Prime：先看到的词
Target：随后要认出的词
```

课件原例：

```text
Prime: tape
```

会预激活：

```text
glue, sticky, circle, grape
```

### 4.2 三种 priming

| 类型 | Prime → Target | 关系 |
|---|---|---|
| **Semantic priming（语义启动）** | tape → glue / sticky / circle | 意义相关 |
| **Phonological priming（音系启动）** | tape → grape | 发音或押韵相关 |
| **Morphological priming（形态启动）** | tape → taped / taping | 同一词根 + 不同形态 |

![[AHGC7315-Psycholing-P27.png]]

### 4.3 为什么重要？

Priming 说明 mental lexicon 不是一个个彼此隔绝的文件柜，而是相互连接的网络。激活一个词，会顺带激活相关词。

## 5. Negative priming（负启动）与 Stroop task

**Negative priming（负启动）**在这里指：一个干扰项必须被压住、抑制，否则会妨碍你完成当前任务。

经典例子是 **Stroop task（斯特鲁普任务）**：

```text
任务：只念出文字的“墨水颜色”，不要念文字本身。
```

#### Congruent（一致）

```text
BLUE        RED
（蓝色字）  （红色字）
```

文字意义和墨水颜色一致，容易。

#### Incongruent（不一致）

```text
BLUE   ← 但印成红色
RED    ← 但印成蓝色
```

你必须压制自动读词，改报颜色，因此更慢、更容易错。

中文也会出现同样干扰：当字的 lexical meaning 与 ink color 冲突时，报颜色明显更难。

## 6. Garden path sentence（花园小径句）★★★

### 6.1 人话解释

听句子时，人只能从左到右实时 processing，不能先偷看结尾。若前面的词暂时支持两种结构，大脑会先选常见的一条；后面的词一来发现选错，只能 **reanalyse（重新分析）**。

这就是 **temporarily ambiguous sentence（暂时歧义句）**，也叫 **garden path sentence**。

关键不是“最后永远有两种意思”，而是：

```text
读到中途：先走一条路
看到后面的词：发现走不通
只能回头重建
```

### 6.2 经典原例

```text
The horse raced past the barn fell.
```

#### 第一次错误解析

读到 `The horse raced past the barn`，容易理解成：

```text
The horse raced past the barn.
马跑过了谷仓。
```

但后面又出现 `fell`，于是这个 parse 出问题：一个主句里出现了 `raced` 和 `fell` 两个主要动词。

#### 正确解析

```text
The horse [that was raced past the barn] fell.
那匹被带着跑过谷仓的马摔倒了。
```

这里 `raced past the barn` 是 reduced relative clause（简化关系从句）的一部分，修饰 `the horse`。

![[AHGC7315-Psycholing-P33.png]]

### 6.3 中文 garden path

课件例子：

```text
小王削苹果的刀不见了。
```

读到 `小王削苹果` 时，容易先理解成“小王在削苹果”；看到 `的刀`，才发现 `削苹果的` 修饰 `刀`：

```text
小王 [削苹果的刀] 不见了。
```

不是“小王在削苹果”，而是“那把用来削苹果的刀不见了”。

### 6.4 考试答题模板

```text
It is temporarily ambiguous because ______ can initially be parsed as ______,
but after hearing ______, the parser must reanalyse it as ______.
```

答题时一定同时写出：

1. 一开始的错误结构；
2. 后面的词怎样迫使人重分析；
3. 最终的正确结构。

## 7. Brain and language（更低优先级）

### 7.1 四个基础词

| 术语 | 人话 |
|---|---|
| **Cortex（皮层）** | 脑表面，接收感觉、发动动作、储存记忆和语法知识 |
| **Cerebral hemispheres（大脑半球）** | 左、右半球 |
| **Lateralization（偏侧化）** | 某些功能主要位于一侧；语言多在左脑 |
| **Localization（定位）** | 某些功能与特定脑区相关 |

`corpus callosum（胼胝体）` 连接左右半球，使两边可以交换信息。

## 8. Broca’s and Wernicke’s aphasia ★★★

### 8.1 Aphasia 是什么？

**Aphasia（失语症）**是脑损伤造成的 language disorder。

| 类型 | 受损区域 | 课件比喻 |
|---|---|---|
| **Broca’s aphasia** | Broca’s area（motor speech area） | broken **grammar book** |
| **Wernicke’s aphasia** | Wernicke’s area（comprehension + lexical selection） | broken **dictionary** |

### 8.2 一眼区分

| 对比 | **Broca’s aphasia** | **Wernicke’s aphasia** |
|---|---|---|
| Speech flow | **slow, labored, effortful** | **fluent，intonation 看似正常** |
| 核心问题 | **agrammatical（语法缺失）** | comprehension / lexical selection 问题 |
| 典型表现 | 少 articles、prepositions、pronouns、auxiliaries、`-ed` 等 | nonsense words；naming objects 困难；内容难懂 |
| 一句话辨认 | **说得很费劲，像电报文** | **说得很流利，但内容混乱** |

![[AHGC7315-Psycholing-P45.png]]

### 8.3 最常考的两个误解

| 错误说法 | 正确说法 |
|---|---|
| Broca’s aphasia = 完全听不懂 | 课件重点是 speech production / grammar，不能简单说成完全 comprehension loss |
| Wernicke’s aphasia = 说不出话 | 通常是 fluent speech，但 meaning、lexical selection、comprehension 出问题 |

## 9. Critical Period Hypothesis for L1（第一语言关键期）★★★

### 9.1 和 L2 的差别

| L1 critical period（本章） | L2 critical period（上一章） |
|---|---|
| 课件的立场更明确：critical period **确实存在** | 更常表述为 **tendency / trend** |
| 时间约从 birth 到 **middle childhood** | exact critical age 争议更大 |
| 错过后通常仍能学词汇，但完整 grammar 很难获得 | 晚学者可能 grammar 很好，但 accent 仍明显 |

L1 关键期的精确截止年龄仍未确定，但“存在关键窗口”是课件强调的结论。

### 9.2 Genie 与 Chelsea

两名儿童都因极端原因错过了正常语言输入窗口。

| 个案 | 后来能做什么 | 仍缺什么 |
|---|---|---|
| **Genie** | 学到大量 vocabulary；非语言沟通能力好 | articles、auxiliary verbs、inflectional suffixes、question words；复杂句和问句 |
| **Chelsea** | 后来也学到大量 vocabulary | 仍没有完整 grammar |

结论不是“错过关键期后什么都不能学”，而是：

```text
Vocabulary can still develop.
Full adult-like grammar is very difficult to acquire.
```

Genie 的语言活动还被发现异常地偏向右侧半球；Chelsea 的语言能力则较平均分布。课件用这些现象说明早期语言输入会影响 brain organization。

## 10. Brain imaging（低优先级）

| 技术 | 主要用途 |
|---|---|
| **MRI** | 高分辨率看脑结构 |
| **CT scan** | 用 X-ray 看结构，可显示 lesion（损伤） |
| **fMRI** | 看任务期间脑活动 |
| **EEG（electroencephalogram）** | 记录脑电活动 |
| **fNIRS** | 通过近红外光观察脑活动 |

记忆：

```text
MRI / CT → 主要看结构
fMRI / EEG / fNIRS → 主要看活动
```

## 考前最后 3 分钟

1. **Bottom-up 从声音往上；top-down 用语境往下预测。**
2. **RT 越长，通常代表 lexical retrieval 越难。**
3. **Priming = related word 先激活目标词。**
4. **Tape→glue 是 semantic；tape→grape 是 phonological；tape→taped 是 morphological。**
5. **Garden path 的核心是 temporary ambiguity + reanalysis。**
6. **Broca = 费力、缺语法；Wernicke = 流利、意义混乱。**
7. **Broca 缺 function words / grammatical endings；Wernicke 则有 naming 与 lexical selection 问题。**
8. **L1 关键期错过后仍可学 vocabulary，但完整 grammar 很难。**
