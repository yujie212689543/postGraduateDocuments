## 1. Priming effect（启动效应）★★

**Priming（启动）**就是一个相关词先帮另一个词“热身 / pre-activate（预激活）”。所以目标词之后出现时，我们会更快做 lexical retrieval（词汇提取）或 lexical decision（词汇判断）。

例：看到/听到 `tape` 后，脑中和它有关系的 `glue`、`sticky`、`circle`、`grape` 会被部分激活。

![[AHGC7315-Psycholing-P27.png]]

| 类型 | prime → target | 为什么有关 |
|---|---|---|
| **Semantic priming（语义启动）** | tape → glue / sticky / circle | 意义相关 |
| **Phonological priming（音系启动）** | tape → grape | 发音相近/押韵 |
| **Morphological priming（形态启动）** | tape → taped / taping | 同一个 root + 不同 morphology |

### 不要混：negative priming（负启动）

**Negative priming（负启动）**是要压制一个干扰项（distractor）的情况。经典 **Stroop task（斯特鲁普任务）**：要求你念 ink colour，不念文字；如果文字是 `BLUE` 却印成红色，文字意义会干扰颜色命名，所以更慢、更容易错。

## 2. Garden path sentences（花园小径句）★★★

### 最简单的理解

读句子时，大脑是一个词一个词往前走的，不能先看到结尾再决定开头。因此碰到能有两种暂时分析的地方，大脑会先选看似最合理的一条路；后面的词一来发现走错，只能回头重建结构——这就是 **garden path sentence（花园小径句）**。

课件定义：a temporarily ambiguous sentence in which a constituent can fit into a sentence in two different ways。

```text
The horse raced past the barn fell.

第一次读：The horse [raced past the barn].
          （把 raced 当主句动词）
看到 fell：发现主句还没有动词 → 前面分析走错。

正确：The horse [that was raced past the barn] fell.
          ↑ “被赶着经过谷仓的马”是一个长 NP
```

![[AHGC7315-Psycholing-P33.png]]

**考题回答模板：**“It is temporarily ambiguous because `raced past the barn` can initially be parsed as the main VP, but after `fell` it must be reanalysed as part of a reduced relative clause modifying `the horse`.”

### 中文例子（课件）

`小王削苹果的刀不见了`：读到“削苹果”时容易理解成“小王削苹果”，读到“的刀”才改为“[削苹果的]刀”。

| garden path 的核心 | 不是句子最终有两个意思，而是 **读到中途暂时有两种分析，后来被迫重分析**。 |

## 3. Broca 与 Wernicke aphasia（失语症）★★★

**Aphasia（失语症）** = caused by brain damage 的 language disorder。课件用两个区域作简化模型：

![[AHGC7315-Psycholing-P45.png]]

| 对比 | **Broca’s area / aphasia** | **Wernicke’s area / aphasia** |
|---|---|---|
| 课件记忆比喻 | motor speech area；**grammar book** | comprehension + lexical selection；**dictionary** |
| 损伤后 | **labored, slow, effortful speech** | **fluent speech**，intonation 看似正常 |
| 语法/词汇 | **agrammatical**：漏 articles, prepositions, pronouns, auxiliaries, `-ed` 等 | 可能有 nonsense words，naming objects 困难，内容不通 |
| 一句话辨认 | **说得很费力、像电报文** | **说得很流利、但意思混乱** |

![[AHGC7315-Psycholing-P47.png]]

![[AHGC7315-Psycholing-P50.png]]

**最易错：**Broca = “不能理解”并不准确；课件的重点是 speech production/grammar 的困难。Wernicke = “不会说”也不准确；它通常 speech fluent，但 comprehension / lexical selection 有问题。

## 4. Critical period hypothesis for L1（L1 关键期假说）★★

它和上一章 L2 的说法不同：

| L1 critical period（本章） | L2 critical period（上一章） |
|---|---|
| 课件说 **certain（确定存在）** | 是 tendency/trend（趋势） |
| 从 birth 到 roughly middle childhood | 精确关键年龄仍争议 |
| 错过后，词汇可学，但成人式 grammar 往往无法完整获得 | 晚学者可能 grammar 好但有 accent |

**L1 critical-age hypothesis：**获得 native language grammar 的能力在 birth 至 middle childhood 发展；过了 critical period，大多数人很难完全习得 grammar 和 adult-like language performance。

课件例子：**Genie** 在 14 岁前几乎没有语言输入；之后能学很多 vocabulary、非语言沟通不错，但始终缺 articles、auxiliaries、inflectional suffixes、question words，也难造 complex sentences/questions。**Chelsea** 同样学到大量 vocabulary，却没有完整 grammar。

![[AHGC7315-Psycholing-P53.png]]

**考场要点：**不要写成“错过关键期什么都学不了”。正确是：仍可能学 words/vocabulary，但完整 grammar 特别困难。

## 5. 一眼区分表

| 概念 | 问自己什么 | 答案关键词 |
|---|---|---|
| priming | 一个词为什么让另一个词更快？ | pre-activation / related word |
| garden path | 为什么读到后面要“回头理解”？ | temporary ambiguity / reanalysis |
| Broca aphasia | 为什么说话慢且漏功能词？ | grammar book damaged / agrammatical |
| Wernicke aphasia | 为什么流利却不通？ | dictionary/comprehension/lexical selection damaged |
| L1 critical period | 错过后还能学什么？ | vocabulary can develop; full grammar difficult |
