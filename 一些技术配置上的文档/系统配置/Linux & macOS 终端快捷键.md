
> **提示**：文中 `Ctrl` 表示 Control 键，`Alt` 在 macOS 上通常对应 **Option (⌥)** 键。若 Option 不生效，请在终端设置中勾选“将 Option 作为 Meta 键”。

## 1. 快速移动光标
| 快捷键 | 作用 | 说明 |
|--------|------|------|
| `Ctrl + A` | 跳到行首 | 快速回到开头修改 |
| `Ctrl + E` | 跳到行尾 | 快速回到末尾 |
| `Alt + B` | 向左跳一个单词 | 移动到上一个单词开头 |
| `Alt + F` | 向右跳一个单词 | 移动到下一个单词末尾 |
| `Ctrl + F` | 向右移动一个字符 | 相当于右键 |
| `Ctrl + B` | 向左移动一个字符 | 相当于左键 |

## 2. 删除/剪切
| 快捷键 | 作用 | 说明 |
|--------|------|------|
| `Ctrl + U` | 删除光标前全部字符 | 剪切到行首，常用 |
| `Ctrl + K` | 删除光标后全部字符 | 剪切到行尾 |
| `Ctrl + W` | 删除光标前一个单词 | 向后删除单词（空格分隔） |
| `Alt + D` | 删除光标后一个单词 | 向前删除单词 |
| `Ctrl + H` | 删除光标前一个字符 | 相当于退格键 |
| `Ctrl + D` | 删除光标后一个字符 | 相当于 Delete 键，无字符时退出终端 |

## 3. 撤销与重做
| 快捷键 | 作用 | 说明 |
|--------|------|------|
| `Ctrl + _` 或 `Ctrl + /` | 撤销上一次编辑 | 恢复刚刚删除的内容 |
| `Alt + R` | 恢复当前行到原始状态 | 如果你改乱了，一键恢复原始命令 |

## 4. 历史命令操作
| 快捷键 | 作用 | 说明 |
|--------|------|------|
| `Ctrl + P` | 上一条命令 | 相当于上箭头 |
| `Ctrl + N` | 下一条命令 | 相当于下箭头 |
| `Ctrl + R` | 反向搜索历史 | 最实用！输入关键字实时匹配 |
| `Ctrl + S` | 正向搜索历史 | 可能被终端流量控制占用，需先 `stty -ixon` 解除 |
| `Alt + .` | 粘贴上一条命令的最后一个参数 | 例如 `ls /tmp` 后按 `Alt+.` 得到 `/tmp` |

## 5. 控制终端本身
| 快捷键 | 作用 | 说明 |
|--------|------|------|
| `Ctrl + L` | 清屏 | 相当于 `clear` 命令 |
| `Ctrl + C` | 中断当前运行的程序 | 强制终止执行中的命令 |
| `Ctrl + Z` | 挂起当前程序 | 可用 `fg` 恢复前台运行 |
| `Ctrl + D` | 退出当前 shell | 相当于 `exit` |
| `Ctrl + S` / `Ctrl + Q` | 锁定/解锁终端滚动 | 误触 `Ctrl+S` 导致终端卡住？按 `Ctrl+Q` 恢复 |

## 6. 其他实用技巧
- **自动补全**：按 `Tab` 补全命令、文件名、路径。连按两次 `Tab` 显示所有可能选项。
- **粘贴剪切板内容**：`Ctrl + Shift + V`（Linux / 多数终端），macOS 终端的粘贴是 `Cmd + V`，但在 shell 内 `Ctrl+V` 通常用于转义，建议直接用 `Cmd+V`。
- **查看所有快捷键**：在 bash 中输入 `bind -P` 或在 zsh 中输入 `bindkey`。

## 快速记忆规律
- **Ctrl 系**：控制或基础编辑（A 首 E 尾，U 删前 K 删后，W 删词）。
- **Alt 系**：针对单词的精细操作（B 前 F 后，D 删后词）。
- **搜索历史**：`Ctrl+R` 是救命稻草，试试看。

## macOS 特别提醒
- 如果 `Alt + B/F/D` 不生效，请打开 **终端.app → 设置 → 描述文件 → 键盘**，勾选“将 Option 键作为 Meta 键”。
- 也可直接使用 **Emacs 风格的快捷键**（终端默认就是这套），无需额外配置。
