# 江苏网络强省建设优秀实践成果申报表 — 二、成果概述（第一版）

无锡政务大模型公共服务平台由无锡市市域社会治理现代化指挥中心联合无锡市数字新基建有限公司共同打造。市城运中心是江苏省首个以数字底座为核心的"城市大脑"，正处级建制公益一类事业单位，由市数据局主管，负责协调推进治理数字化转型和"一网统管"体系建设，承担市级重大政务信息化项目集中代建、政务信息化基础设施与城市数字底座规划建设等职能。平台秉持"算力共享+模型复用+安全协同+标准规范"的核心理念，确立"统一底座、分级接入、按需调用"的架构原则，集约化建设政务大模型公共服务平台，提供统一的模型服务网关、算力推理调度引擎及全栈安全审计能力，支撑各部门业务场景的敏捷挂接与能力复用，从机制上规避"信息孤岛"与重复投资。平台集"算力、数据、模型、应用、安全"于一体，推动政务服务的数字化与智能化升级。平台聚焦政务服务、社会治理、机关办公、辅助决策四大领域，服务对象涵盖全市各委办局及其业务系统、基层网格员、办事群众和企业。

平台采用分层解耦设计，自下而上分为基础设施层、基础平台层、模型层、技术能力服务层和应用场景层，并配套服务保障与标准规范体系。基础设施层统筹全市政务智算资源，组建12节点服务器集群（算力规模约26.88P），采用华为昇腾910B服务器构建智能算力中心，依托国产华为算力与银河麒麟操作系统实现全栈国产化适配，通过智能算法动态分配算力资源实现最优利用。基础平台层以百度智能云千帆平台为核心AI底座，配备安全干预机制，支持自定义干预词和规则精准过滤敏感内容；知识库基于无锡城市大数据中心，构建预训练语料库与政务数据。模型层采用"全量+轻量"协同架构，全量模型作为底层智能中枢负责复杂分析与知识库更新，轻量化模型提供实时响应，已部署DeepSeek、通义千问、GLM、文心一言、智谱等18个主流模型及无锡"知惠"政务大模型，提供大语言、多模态、Embedding、Rerank、OCR、TTS、ASR等全链路模型服务，并运用知识蒸馏、参数剪枝降低模型规模提升推理速度。技术能力服务层提供标准化平台接口和Agent/智能体编排工具，深度融合大模型泛化推理能力与可视化开发范式，针对简易任务可基于自然语言直接调用大模型完成需求执行，针对复杂场景可通过拖拽式工作流组合大模型、API接口与知识库等模块构建跨系统协同智能体，推动AI由"问答助手"升级为"自动化业务处理器"。服务保障以"模型-数据-安全"一体化为核心，提供监控、告警、备份、恢复等运维能力。标准规范通过明确算法透明度、数据合规性、伦理约束等指标，有效防范虚假信息传播、隐私泄露及算法歧视等风险。技术路线凸显自主可控，底座平台扩展性强，适配主流开源模型。

平台目前已接入21个委办局业务系统，支撑78个政务智能体投入实战，覆盖智能问答、多模态审查、公文纠错、工单处理等14类应用场景。具体落地场景包括：（一）网格通智能问答（格智AI助手），联合市政法委全面收录"两张清单"、矛盾纠纷化解等150余项公开内容，为网格员提供法律与调解知识库支持，简化处理流程，降低人力依赖，提升基层治理精细化和智能化水平。（二）数字人智能问询，集成ASR、TTS及办事问答服务，打造数字人交互助手，为群众提供精准办事指引和政策解读。（三）网站群智能问答，依托"知惠"政务大模型构建集语义理解、生成式对话及多轮会话能力于一体的智能问答平台，实现全市各区办事指南的快速检索，解决了信息分散、检索困难的问题。（四）经济问数即问即查，借助平台实现滨湖经济运行数据的快速统计和直观展示，为决策者提供实时准确的经济数据支持。（五）智能交评，作为国内首创的交通影响评价智能化评审解决方案，深度融合行业标准与技术规范，依托自主研发的大模型架构构建本地化专业知识图谱，可自动生成专业评审报告，构建人机协同的闭环评审体系，已完成多场景实测验证。（六）智能综窗，完成市工程审批综合窗口的办件分发，集成OCR和多模态大模型，支持纸质表格、扫描件、照片等多格式输入，实现身份证、营业执照等证照信息的智能提取与自动填充，采用知识图谱精准匹配承办部门。（七）施工图审查矩阵，将审查效率提升超100倍（从半小时60余张提升至近1000张），覆盖报审、监审、审查、监管全流程，基于自研图像识别算法精准定位图签栏信息并自动分类入库。（八）积水智能体，采用多智能体协同架构，通过解析气象预警精准划定监控区域，结合多模态大模型智能研判积水场景，实现从预警、识别、研判到上报、处置的全流程闭环管理。（九）AI代码审计，由爱马仕（Hermes Agent）接入平台AI大模型能力构建，调用平台大语言模型与代码理解能力对目标系统进行自动化代码审查。已成功应用于智慧社区后台管理系统（zhsq-backstage-2.0，含OAuth2认证授权中心、Spring Cloud Gateway网关、40+业务微服务模块、Flowable工作流引擎、10个自定义Starter公共组件），产出两份审查报告——代码安全审查报告（发现10个原始安全问题，经AI过滤后保留7个有效漏洞，含HIGH级6个，覆盖CORS配置错误、凭据明文传输、AES硬编码密钥、SSL证书验证禁用、RSA私钥硬编码等）和全面代码审查报告（发现54+项问题，含12个CRITICAL、12个HIGH，覆盖安全漏洞、数据一致性问题、性能瓶颈、并发缺陷等），验证了平台AI大模型能力在软件工程质量保障领域的实际落地可行性。

平台主要特点体现在五个方面：一是"算力共享"，通过统一算力调度实现"按需取用、即插即用"，相比分散建设算力利用率显著提升，各部门不需要重复"造轮子"，只需"拧螺丝"，极大降低了应用门槛。二是"模型复用"，集约部署18个主流模型并提供统一API接口，加速AI在全市范围内的普及。三是"安全协同"，确立了"数据不出政务网，模型只跑安全域"的铁律，引入安全电子围栏技术，构筑贯穿全链路的安全防控体系，通过输入端对抗防御与输出端多层级伦理审核，系统性阻断提示词注入、虚假信息及隐私泄漏风险，实现训练与推理在政务网内部的闭环运行。四是"标准规范"，制定政务大模型对接服务标准规范及数据标注规范，推动大模型应用规范化落地。五是"全栈国产化"，采用自主可控框架，依托国产华为算力与银河麒麟操作系统，确保技术安全可控。在经济社会效益方面，平台实现了政务服务"秒级响应"，推动城市治理从"被动应对"向"主动预警"转变，整合全市政策法规数据实现"智能问答—精准推送"，赋能基层服务均等化，并通过技术赋能传统产业降低人工成本、推动"放管服"改革和透明化决策。平台已先后入选2025年数字政府服务能力生成式人工智能应用优秀创新案例（中国软件评测中心）和2025年度中国政务服务智能应用十佳创新案例（中国信息化研究与促进网）。【待补充：未来发展预期、具体财务与投资数据、专利及知识产权信息】
