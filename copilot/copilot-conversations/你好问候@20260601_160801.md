```python
import requests

url = "https://api.deepseek.com/v1/chat/completions"  # DeepSeek 的端点
api_key = "你的 API Key"

headers = {
    "Authorization": f"Bearer {api_key}",  # 你的笔记中提到过 header 和 Bearer token

}

# 你笔记中强调过：AI 世界到处都是 JSON [^2]
data = {
    "model": "deepseek-chat",  # 模型名称
    "messages": [

        {"role": "user", "content": "请用 Python 写一个 hello world 程序。"}
    ],
    "temperature": 0.7  # 你笔记中提到的 API 参数
}

# 重点：POST 请求，传入 json=data [^1]
response = requests.post(url, headers=headers, json=data)

# 重点：拿到返回的 JSON [^2]
result = response.json()

# 提取 AI 的回复
print(result["choices"][0]["message"]["content"])
```

## 一、配置 DeepSeek API（云端）

这是最常用的方式，与你自己写 Python 代码调用的原理完全一致，只是把 API Key 和端点填到插件设置里。

### 步骤

1. **安装 Obsidian Copilot 插件**  
   若还没安装：  
   - 打开 Obsidian → 设置 → 社区插件 → 浏览  
   - 搜索 `Copilot`，安装并启用。

2. **进入插件设置**  
   - 设置 → 社区插件 → 找到 Copilot → 点击齿轮图标 ⚙️

3. **配置 Provider（服务商）**  
   - 在 **Provider** 下拉框中选择 `OpenAI`（因为 DeepSeek 兼容 OpenAI 的 API 格式）

4. **填写 API Endpoint 和 Key**  
   - **API Base URL**：填入 `https://api.deepseek.com/v1`  
   - **API Key**：填入你的 DeepSeek API Key（以 `sk-` 开头）  
   - **Model Name**：填写 `deepseek-chat`（或其他模型名如 `deepseek-reasoner`）

5. **保存并测试**  
   - 回到 Obsidian，在 Copilot 对话窗口中发送一条消息，如果能正常回复，说明配置成功。

---

### 注意事项

- 不要在笔记或共享文档中明文保存你的 API Key，Obsidian 的 `data.json` 文件会加密存储。
- DeepSeek 目前提供一定免费额度（如新用户赠送 500 万 tokens），但**不是永久免费**，使用后会按量计费。
- 网络问题：如果访问 `api.deepseek.com` 不稳定，可以尝试使用代理或国内镜像端点（官方是否有国内端点请查阅最新文档）。

## 二、配置本地模型（永久免费）

如果你想**完全免费且离线使用**，推荐用 **Ollama** 运行本地模型。

### 步骤

1. **安装 Ollama**  
   从 [ollama.com](https://ollama.com) 下载安装，命令行运行 `ollama pull deepseek-coder` 或 `ollama pull qwen2.5` 等（推荐 7B/8B 参数模型，普通电脑即可运行）。

2. **启动 Ollama 服务**  
   `ollama serve`（默认监听 `http://localhost:11434`）

3. **配置 Obsidian Copilot**  
   - 在 Copilot 设置中，**Provider** 选择 `Ollama`  
   - **API Base URL** 填入 `http://localhost:11434`  
   - **Model Name** 填入你在 Ollama 中拉取的模型名（如 `deepseek-coder:7b`）  
   - 保存并测试。

4. **优点**  
   - 零成本，无限使用。  
   - 数据不出本地，隐私安全。
