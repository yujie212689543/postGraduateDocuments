# 军队文职岗位筛选方法论与经验总结

> **用途**: 方便未来重新用大模型筛选岗位时，快速复用筛选策略和个人条件
> **生成日期**: 2026年6月4日
> **数据源**: 军队人才网(81rc.81.cn) 2024-2026年岗位计划表

## 一、个人条件档案（可直接粘贴给大模型）

```markdown
## 我的背景

### 基本信息
- 性别: 男
- 出生年份: 2000年
- 出生地：无锡
- 2028年硕士毕业时: 28岁
- 年龄限制: 初级岗(九级文员/助理工程师)限35周岁 → 富裕7年 ✅
- 中级岗(八级文员/工程师)限45周岁 → 远期无忧 ✅

### 学历
- 本科: 二本院校，软件工程专业，全日制
- 硕士: 澳门大学(University of Macau)，数据科学-计算语言学(Data Science - Computational Linguistics)，全日制，2028年毕业

### 军事背景
- 义务兵2年，服役期满正常退伍
- 非军官，非士官，普通义务兵

### 职业资格
- 暂无（建议考取软考中级/高级、PMP等）

### 政治面貌
- 非党员（建议争取入党）

### 目标城市（按优先级）
1. 苏州（首选，家乡或定居目标）
2. 无锡（首选）
3. 上海（次选）
4. 北京（可接受）

### 工作偏好
- 偏好工作强度适中、生活便利的岗位
- 优先考虑武装部/国防动员系统（与服役经历直接相关）
- 也可接受工程技术岗（软件开发/数据分析方向）
- 对纯行政/文职工作也持开放态度

### 核心优势
1. 2年义务兵 — 满足"具有2年以上服役经历"硬门槛
2. 软件工程本科 — 工学大类(B08)全覆盖
3. 数据科学+计算语言学硕士 — CS/NLP交叉稀缺技能
4. 澳门大学全日制硕士 — 需教育部留服中心学历认证

### 核心劣势
1. 澳门大学非内地双一流/985/211 — 约71%岗位被排
2. 本科二本 — 部分岗位对第一学历有要求
3. 义务兵仅2年，不满5年无法享受加分
4. 非党员 — 军委机关/部分武装部岗位要求党员
```

## 二、数据获取流程

### 2.1 数据源

| 数据类型 | 官方渠道 | 备注 |
|---------|---------|------|
| 岗位计划表 | 军队人才网 http://81rc.81.cn | 每年10-11月发布下一年度招考 |
| 入围/录用名单 | 同上 + 中国军网 http://www.81.cn | 分批分单位公示 |
| 备考资料 | 粉笔网盘 https://www.fenbi.com/fpr/doc-user-v2/dir/36469 | 含进面名单和岗位表汇总 |

### 2.2 Excel文件结构

军队文职岗位表为标准格式，20列：

```
列0: 岗位代码 (如 2026000001)
列1: 用人单位序号
列2: 用人单位名称
列3: 岗位类别 (行政管理/工程技术/高等教育/医疗等)
列4: 岗位名称 (干事/助理工程师/助教等)
列5: 从事工作 (具体工作描述)
列6: 招考数量
列7: 入围比例 (1:3或1:5)
列8: 来源类别 (高校毕业生/社会人才/两者均可)
列9: 学历 (全日制本科/全日制研究生(硕士)等)
列10: 学位 (学士/硕士/硕士以上等)
列11: 所学专业 (研究生专业代码+本科专业代码)
列12: 考试专业科目 (数学1/管理学/教育学/会计等)
列13-14: 职称要求 (高校毕业生/社会人才)
列15-16: 职业资格要求
列17: 其他条件 (关键筛选字段!)
列18: 工作地点
列19: 咨询电话
```

### 2.3 文件解析要点

- **前6行是标题/表头**，实际数据从第7行(row index 6)开始
- **"其他条件"(列17)是关键筛选字段**，包含双一流限制、服役要求、性别、党员等
- **"所学专业"(列11)包含研究生和本科两个层次**，格式如"研究生:A0812计算机科学与技术\n本科:B080901计算机科学与技术"

## 三、筛选策略与经验

### 3.1 核心筛选逻辑（按优先级）

```
第1层: 城市筛选
  ├─ 目标城市: 苏州=无锡>上海>北京
  └─ 扩展城市: 南京/镇江/常州/杭州/嘉兴/宁波等（高铁30-60分钟）

第2层: 学历门槛
  ├─ 硕士可报: "硕士" in 学历字段
  └─ 本科亦可: 用硕士报本科岗 = 降维打击

第3层: 双一流/985/211限制 ⚠️ 最关键!
  ├─ 有这些字样的 → 排除（澳门大学不符合）
  └─ 无这些字样的 → 保留

第4层: 专业匹配
  ├─ 精准: 计算机/软件/数据/智能/网络
  ├─ 大类: A08工学/B08工学/A07理学/A12管理学
  └─ 交叉: 语言/翻译/信息资源管理

第5层: 服役经历硬门槛 🎖️ 隐藏王牌!
  ├─ 有"2年以上服役经历" → 竞争极低，优先投
  └─ 无此要求 → 正常竞争
```

### 3.2 关键发现：服役经历是核心壁垒

本次分析最大的发现：

> **"具有2年以上服役经历"是一个被大多数人忽略的硬过滤条件。**

在2026年长三角地区（苏州/上海/无锡/南京/杭州/宁波等）共有**28个岗位**明确要求服役经历，且**全部无双一流/985/211限制**，专业要求多为工学/管理学大类。这些岗位的竞争者不是普通CS硕士，而是同样有服役经历的退伍军人——其中拥有硕士学历+CS专业的极少。

### 3.3 避免的陷阱

1. **不要只看"岗位名称"，要看"从事工作"描述** — 军委联合参谋部的"秘书"岗实际要求文本数据处理+数据挖掘
2. **"全日制本科以上"不包含"硕士"字样** — 搜索时要用"本科"或"硕士"或"研究生"，不能只用"硕士"
3. **专业代码A08工学大类是隐藏通道** — 软件开发归入工学，很多武装部岗只要求工学大类
4. **先面试后笔试岗极少** — 2026年仅77个，且多为文体岗位（声乐/舞蹈/体育），CS专业基本无缘
5. **免笔试岗几乎都要求博士或双一流硕士** — 对澳门大学硕士不友好

### 3.4 筛选关键词总结

#### 必筛关键词（排除用）
```
双一流, 985, 211 → 排除
```

#### 专业匹配关键词（按优先级）
```
精准: 计算机科学与技术, 软件工程, 智能科学与技术, 大数据技术与工程, 人工智能
通用: 计算机, 软件, 网络, 智能, 数据, 信息, 计算
大类: A08工学, B08工学, A07理学, B07理学, A12管理学, B12管理学
管理: 管理科学与工程, 工商管理, 公共管理, 信息资源管理
交叉: 语言, 翻译, 外语, 教育, 新闻, 出版
```

#### 工作描述关键词
```
数据, 文本, 语言, 分析, 挖掘, 系统, 软件, 开发, 网络, 信息
```

## 四、竞争对手分析框架

### 4.1 竞争层级模型

```
层级1 — 服役专属岗 (Tier 0):
  竞争者: 有2年服役+本科以上+工学/管理学专业
  全国预估: 每岗1-10人
  你的优势: 硕士降维 + CS科班 + 计算语言学稀缺

层级2 — 精准CS岗 (Tier 1):
  竞争者: CS/软件/数据硕士，无双一流学历
  全国预估: 每岗20-80人
  你的优势: 服役优先录用 + 计算语言学差异化

层级3 — 通用工学/管理岗 (Tier 2):
  竞争者: 任何工学/管理学硕士
  全国预估: 每岗50-200人
  你的优势: 服役优先录用

层级4 — 边缘匹配岗 (Tier 3):
  竞争者: 相关专业硕士
  全国预估: 每岗80-300人
  你的优势: 有限
```

### 4.2 服役经历的实际竞争力

```
全军每年硕士报考:        ~50,000人
有服役经历的硕士:         ~500人 (1%)
有服役+CS/工学大类:       ~50人
有服役+CS/工学+长三角:    ~10人
有服役+CS/工学+苏州:      ~2-3人
                              ↓
              服役专属岗的真实竞争: 个位数
```

## 五、未来趋势预判

### 5.1 三年数据趋势

| 指标 | 2024 | 2025 | 2026 | 方向 |
|------|------|------|------|------|
| 全军总岗位 | 26,360 | 28,074 | 18,596 | 📉 缩招 |
| 技术岗占比 | 23% | 28% | 29% | 📈 上升 |
| 双一流限制率 | ~65% | ~68% | ~71% | 📈 趋严 |
| 服役专属岗(长三角) | 不详 | ~16 | ~28 | 📈 增长 |
| 苏州服役岗 | 0 | 0 | 2 | 🆕 突破 |

### 5.2 对2028年毕业生的预判

1. **全军总岗位可能继续下降**，但技术岗占比会继续提升
2. **双一流限制可能更严**，但服役专属岗不受影响
3. **武装部/国防动员系统的服役专属岗可能增加**（全军推行退役军人优先政策）
4. **计算语言学/AI相关岗位可能增加**（军事智能化转型）
5. **港澳高校学历的接受度逐步明确**（需关注最新政策）

## 六、给未来大模型筛选的提示词模板

### 6.1 基础筛选模板

```
我需要军队文职岗位的Excel数据（如果本地文件中没有，请在网站上自行下载），请帮我筛选适合我的岗位：

【我的背景】
- 男，2000年出生，2028年硕士毕业时28岁
- 本科：二本，软件工程
- 硕士：澳门大学，数据科学-计算语言学
- 2年义务兵服役经历
- 非党员
- 目标城市：苏州上海>无锡>北京
- 年龄限制：初级岗限35周岁（我28岁，富裕7年，无压力）

【筛选规则】
1. 排除"其他条件"中含"双一流""985""211"的岗位
2. 排除医疗/护理/药剂等医学类岗位
3. 学历需包含"本科"或"硕士"（我可报本科要求以上的所有岗位）
4. 专业需与我的背景匹配：计算机/软件/数据/智能/工学/管理学大类
5. 优先标出含"服役""退役""退伍"字样的岗位（这些是我的核心优势）
6. 按城市优先级排序

请输出每个岗位的：代码、单位、岗位、专业要求、考试科目、入围比、为什么适合我。
```

### 6.2 进阶分析模板

```
基于筛选结果，请帮我进一步分析：

1. 按竞争度将岗位分为四层：
   - Tier 0: 要求服役经历的（竞争极低）
   - Tier 1: CS/数据专业精准匹配的
   - Tier 2: 工学/管理学大类覆盖的
   - Tier 3: 其他边缘匹配的

2. 分析我的三重优势如何组合：
   - 2年义务兵 = 服役经历硬门槛
   - 软件工程本科 = 工学大类覆盖
   - 计算语言学硕士 = 数据+语言交叉

3. 指出哪些岗位可能被一般人忽视但实际非常适合我

4. 预估每层岗位的真实竞争人数
```

## 七、备考建议

### 7.1 考试科目选择

| 路径 | 考试科目 | 备考难度 | 建议 |
|------|---------|---------|------|
| 武装部/管理岗 | **管理学** | 🟢 低（背记） | 主攻 |
| 工程技术岗 | **数学1** | 🔴 高（数学） | 辅攻 |
| 公共科目 | 行测+公基 | 🟡 中 | 通用 |

### 7.2 时间线

```
2026-2027:  系统备考公共科目+管理学
2027年初:   加入数学1复习（为辅）
2027.7:     澳门大学毕业
2027.7-8:   办理教育部留服中心学历认证 + 中联办学习证明（⚠️最关键！）
2027.10-11: 关注军队人才网公告，报名
2027.12:    全军统一笔试
2028.1-3:   面试+体检+政审
```

### 7.3 报名注意事项

1. **学历认证必须在报名截止前完成** — 这是硬门槛，没认证书无法通过资格审查
2. **服役经历需上传退役证** — 提前准备好退役证扫描件
3. **报名时主动勾选"退役军人"身份** — 否则无法享受优先录用
4. **可以同时报多个岗位**（不同考试科目）
5. **入围比例大的优先**（1:5 > 1:3）
