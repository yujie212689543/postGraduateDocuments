对于语料标注，按照要求分为功能性标注、安全性标注两大类，并分别制定了标注要求。所有规则都包含了标注目标、数据格式、标注方法、质量指标等基本标注要素。

# 功能性标注规则要求

## 标注规则概要

### 标注目标

A.精准标识prompt数据质量：要求标注人员对数据prompt的清晰度、相关性、完整性和准确性展开评估，确保数据prompt能清晰传达任务要求。

B.精准标识回答数据质量：标注人员需对数据回答的相关性、准确性、完整性、一致性、专业性和无害性进行评估，保证回答与prompt的要求一致。

C.标识数据所属任务类型：为保障数据的多样性，标注人员要准确标注每条数据的任务类型，例如翻译、问答、摘要、重写、Math等。

D.依据prompt优化回答：在部分场景中，标注人员需根据数据prompt对现有回答进行调整，以提升答案的质量和准确性。

### 数据格式

1.标注格式：使用JSON格式进行标注，以保持标注内容的结构化和可读性，便于标注工具或算法的自动化处理。

2.标注属性：每条语料的组织主要由id、Task、Instruction和Output四个主要的部分组成。

### 标注方法

采用自动化标注工具和人工审查相结合的方法，以提高标注的效率和准确性。具体步骤如下：

第一步，预处理数据。利用自然语言处理技术对数据的任务类型、数据质量等进行分析，并将分析结果作为数据的预标注信息。同时，基于预处理的结果，选择符合需要的数据，制定标注规则，创建标注任务，进行人工标注。

第二步，人工标注数据。由专业的标注人员对数据进行标注，以检测问答数据的相关性、准确性、完整性、连贯性、专业性等等。

第三步，审核标注结果。组织专业的审核人员对标注结果进行逐一审核，以确保标注结果的准确和可靠。

第四步，大模型二次评定分析。大模型对审核通过的数据，再次通过大语言模型等自然语言处理技术对数据的质量、任务类型等进行评定分析，以进一步确保标注结果的准确和可靠。

此外，在标注过程中，要求对全部标注人员进行培训、不定期抽检，并保证抽检合格率达标。对于复杂或模糊的标注任务，需要增加多人标注和审查讨论。

### 质量指标

结合人工抽检及自动化评估，定期评估标注质量。根据数据回答的准确率、一致性和完整性，判定数据是否合格。具体指标有：

从全部通过审核的数据中随机抽样不低于20%数据，人工审核合格率不得低于95%。

对全部通过审核的数据，通过大模型对数据质量等级等进行分析，若分析结果与标注结果不同，则对应数据标注不合格。数据整体合格率不得低于97%。

## 语料标注规定

### 标注规则

A：对政策文件按章节内容进行切分，其中包括关联章节的切分合并。例如：章节六引用了章节四中的部分条款，则文本按章节切分后，章节四会被补充到章节六的文本块中，保持章节六的文本完整性；

B：根据每一个文本块的内容，调用全量模型生成指定数量的问答对，并标注出问答对的来源，例如政策名称及具体条目；

C：标注人员对审核问答对，基于原文出处，审核问答对的完整性、准确性、有效性、逻辑性等，通过审核的问答对会被纳入到SFT数据集中

D：对标注数据集进行清洗和格式转化，去除角标、源文件内容等信息，形成符合SFT数据集格式要求的json格式数据集。

### 语料标注数据表格

为了确保数据的一致性和易处理性，我们制定了统一的数据存储格式。如前所述，每条数据的组织主要由id、Task、Instruction、Output和result五个主要的部分组成。具体的数据格式如下：

| 2 | Task | 标注任务信息 | 随标注任务自动生成 |
| 3 | Instruction | 问答语料中的问题信息 |  |
| 4 | Output | 问答语料中的回答信息 |  |
| 5 | result | 标注结果 |  |

## 标注内容准确性

### 审核机制

1.审核目标

①确保问答对严格符合政策原文核心要求，避免主观臆断

②验证数据格式符合SFT训练规范（问题清晰、回答结构化）

③检测潜在歧义、遗漏或政策理解偏差

④保障数据合规性，规避法律风险

2.三级审核流程

①初审：标注员自检（100%全检）

审核要点：

格式合规性：问题是否采用标准问法（5W1H结构），回答是否包含政策条款编号、原文引用、结论三要素

基础准确性：答案是否与政策原文直接对应，是否存在过度推理

逻辑自洽性：问答是否构成有效对话场景

操作规范：

对照政策原文逐项勾稽验证

标注问题类型标签（如政策解读类/操作指引类/禁止性规定类）

②复审：交叉评审（20%抽检率）

审核要点：

政策理解深度：答案是否完整覆盖政策条款的适用范围、例外情形

边界案例处理：特殊场景问答是否符合政策立法本意

风险点筛查：是否存在可能引发歧义的表述

操作规范：

实行双盲评审机制，不同标注组交叉验证

对高风险领域（如行政处罚、许可要件）实施全量复审

③终审：质量管控组终验（5%抽检率）

审核要点：

整体合规性：问答对是否符合最新政策修订版本

价值导向：回答是否体现政策制定宗旨

训练适配性：数据分布是否平衡（覆盖不同政策章节、问题类型）

操作规范：

开发质量看板，实时监控各维度指标

每月发布质量分析报告，反馈生成流程优化建议

3.质量评估指标体系

|  |  |  |
| --- | --- | --- |
| 指标维度 | 计算公式 | 达标阈值 |
| 格式合规率 | 格式正确样本数/总样本数×100% | ≥98% |
| 政策引用准确率 | 引用正确样本数/引用类样本数×100% | ≥95% |
| 逻辑一致率 | 无矛盾样本数/总样本数×100% | ≥99% |
| 风险点覆盖率 | 覆盖风险点数/总风险点数×100% | 100% |
| 人工复核通过率 | 终审通过数/终审样本数×100% | ≥90% |

4.异常处理机制

①数据回滚：

当某批次数据终审通过率＜80%时，触发全量回滚机制

建立问题数据隔离区，防止污染训练集

②政策更新响应：

开发政策版本比对工具，自动标记需更新数据

设立72小时紧急响应通道处理重大政策调整

5.技术辅助手段

①智能预审系统：

自动提取政策条款核心要素（主体、行为、条件）

②可视化追溯平台：

构建问答对-政策原文的双向链接图谱

展示数据生成、审核全流程轨迹

6.持续改进机制

①月度质量复盘会：

分析TOP10高频错误类型

更新标注规范手册（V2.0已包含37项细化标准）

②动态抽检策略：

根据标注员质量波动调整抽检比例

对新政策领域实施前3个批次100%全检

### 审核标准

1.质检目标

①确保标注结果准确反映政策原文含义，错误率低于行业基准

②维护数据标注一致性，同类政策条款标注方式统一

③保障数据完整性，无遗漏关键政策要素

④符合数据安全与隐私保护规范

2.四维质检体系

①准确性质检

方法：

双重校验：标注员自检+专职质检员100%复核

政策溯源：要求每个标注答案标注对应政策条款编号及段落位置

黄金样本对比：选取5%标注数据与专家标注的黄金样本集比对

标准：

事实性错误（如时间描述错误）零容忍

解释性错误（如政策适用范围误读）发生率＜0.5%

②一致性质检

方法：

交叉验证：不同标注员对相同政策条款的标注结果比对

语义漂移检测：通过词向量分析标注答案的语义相似度

标准：

相同政策条款标注一致性≥95%

核心术语表述标准化率100%

③完整性质检

方法：

要素覆盖检查：对照政策要素清单（主体、行为、条件、责任等）

边界案例测试：构造政策临界场景验证标注完整性

空值检测：使用自动化工具扫描缺失标注字段

标准：

政策要素覆盖率100%

边界案例标注正确率≥90%

④合规性质检

方法：

法律审查：由法务团队抽检5%数据验证合规性

敏感信息筛查：使用NLP模型检测个人信息、商业秘密等

伦理评估：检查是否存在歧视性表述或不当价值导向

标准：

合规性问题零发生

敏感信息泄露风险零容忍

## 质量保证

采用人工抽样校验，具体操作步骤如下：

1.抽样时间设置：

每周标注任务进行抽样，每次抽取1000条已标注语料。

每月进行一次大规模抽样，抽取5000条已标注语料。

每批次语料固定抽样10%进行日常校验。

标注员样本抽取：

不定期对每个标注员的工作进行抽样审核。

从每个标注员的标注中随机抽取一定数量的样本，以评估其工作质量和对标注指南的遵守情况。

2.随机抽样审核：

不定期应用随机抽样方法从已标注语料库中选择样本。

3.审核团队复核：

由专门的审核团队对抽取的样本进行复核。

确保每条标注严格符合标注要求。

4.不合格标注的处理：

对于不符合标注要求的标注，记录并通知原标注员进行修正。

发现内容中包含违法不良信息的（参见安全性标注规则），该批次标注语料作废。

## 后续计划

### 标注流程优化

定期且系统性地评估和优化标注流程，确保标注工作不仅高效运行，而且能够达到高度的准确性。识别并去除可能导致效率降低或错误率上升的瓶颈环节，同时强化那些促进高质量产出的步骤。

### 标注团队培训和发展

定期对标注团队进行培训，包括最新的标注技术、工具使用和数据安全知识。建立团队交流平台，鼓励分享最佳实践和解决标注中遇到的问题，及时组织内部知识分享交流，规避同类问题。

### 数据质量控制

定期进行标注质量检查，包括随机抽检和全面审查。同时我们也会根据质量控制结果，不断调整和优化标注指南和流程。

重视标注数据的质量管理和过程管理，确保数据合规。

### 反馈机制建立

设立标注反馈机制，收集标注者和审核者的意见和建议。定期评估反馈，并据此进行流程或策略的调整。

### 技术和工具升级

跟踪最新的标注技术和工具，我们也会不断评估并引入市场上更先进、功能更强大的标注工具或软件，进一步减少人为错误，提升标注结果的准确性。

优化现有工具，实现工具自动化、智能化，提升工具的适应性和用户友好性。

# 2安全性标注规则要求

## 标注规则概要

### 标注目标

安全性标注：识别并标注出可能带来的安全风险。标注数据用于训练安全多分类算子，以及做大模型安全性对抗训练。

### 数据格式

1.标注格式：使用JSON格式进行标注，以保持标注内容的结构化和可读性，便于标注工具或算法的自动化处理。

2.标注属性：每条语料的组织主要由id、Task、Instruction和Output四个主要的部分组成。

### 标注方法

采用自动化标注工具和人工审查相结合的方法，以提高标注的效率和准确性。具体步骤如下：

第一步，预处理数据。利用自然语言处理技术对数据的任务类型、数据质量等进行分析，并将分析结果作为数据的预标注信息。同时，基于预处理的结果，选择符合需要的数据，制定标注规则，创建标注任务，进行人工标注。

第二步，人工标注数据。由专业的标注人员对数据进行标注，以检测问答数据的相关性、准确性、完整性、连贯性、专业性等等。

第三步，审核标注结果。组织专业的审核人员对标注结果进行逐一审核，以确保标注结果的准确和可靠。

第四步，大模型二次评定分析。大模型对审核通过的数据，再次通过大语言模型等自然语言处理技术对数据的质量、任务类型等进行评定分析，以进一步确保标注结果的准确和可靠。

此外，在标注过程中，要求对全部标注人员进行培训、不定期抽检，并保证抽检合格率达标。对于复杂或模糊的标注任务，需要增加多人标注和审查讨论。

### 质量指标

通过人工审核，确定标注员的准确率、召回率、确保标注的高质量。

## 分类标注规则细化

### 标注标签细则

参考全国网络安全标准化技术委员会发布的《生成式人工智能服务安全基本要求》，我们为大模型主要面临的31种安全风险制定详细的标注指南。每种风险有明确的定义、示例和非示例；每个分类应详细定义其涵盖的内容，并提供具体示例。以下为每个分类的标注指南：

A1违反社会主义核心价值观的内容

定义：任何可能煽动颠覆国家政权、损害国家形象或宣扬恐怖主义等违反社会主义核心价值观的内容。

煽动颠覆国家政权、推翻社会主义制度

定义：内容明确或暗示要颠覆现行政权或推翻社会主义制度。

示例：“我们应该推翻现在的政府”。

危害国家安全和利益、损害国家形象

定义：含有对国家形象进行诋毁、误导或偏见的内容。

示例：“我听说XX国家的人都是...”。

煽动分裂国家、破坏国家统一和社会稳定

定义：内容鼓励或支持国家分裂、社会动荡和破坏社会稳定。

示例：“XX省份应该独立”。

宣扬恐怖主义、极端主义

定义：支持或鼓吹恐怖主义、极端主义的行为和思想。

示例：“为了我们的信仰，我们应该...”。

宣扬民族仇恨、民族歧视

定义：内容包含对某一民族的侮辱、诋毁或持有偏见。

示例：“XX民族的人都是...”。

宣扬暴力、淫秽色情

定义：内容包含对暴力或色情的鼓励、支持或描述。

示例：“她被强行...”。

传播虚假有害信息

定义：散布不真实、误导性或有害的信息。

示例：“我听说吃XX可以治愈所有疾病”。

其他法律、行政法规禁止的内容

定义：任何其他违反国家法律、行政法规的内容。

示例：“这是一个XX制造的非法工具”。

A2包含歧视性内容

定义：任何可能对某一群体或个体进行歧视的内容。

信仰歧视内容

定义：对某一信仰或宗教的贬低或者持有偏见的内容。

示例：“XX教的信徒都是迷信的”。

国别歧视内容

定义：对某一国家或地区的贬低或持有偏见的内容。

示例：“XX国的人都是懒惰的”。

地域歧视内容

定义：对某一特定地区或城市的居民持有的贬低或偏见。

示例：“XX市的人都是乡下人”。

性别歧视内容

定义：基于性别进行的贬低或偏见。

示例：“女性不应该做XX工作”。

年龄歧视内容

定义：基于年龄进行的贬低或偏见。

示例：“老人都不懂技术”。

职业歧视内容

定义：对某一职业的贬低或偏见。

示例：“XX职业的人都不诚实”。

健康歧视内容

定义：对某一健康状况或疾病的患者进行的贬低或偏见。

示例：“他有XX病，远离他”。

其他方面歧视内容

定义：这类歧视不仅仅基于常见的歧视类型（如种族、性别、宗教等），而是基于其他可能的特点或身份来歧视某人。

示例：“穿这种衣服的人都是低能者。”

A3商业违法违规

定义：任何可能侵犯他人知识产权、违反商业道德或泄露他人商业秘密的内容。

侵犯知识产权内容

定义：不当使用或分发他人的知识产权。

示例：“这是我从XX网站非法下载的音乐”。

违反商业道德内容

定义：违背公认的商业行为准则或伦理。

示例：“我们可以通过XX手段绕过他们的规定”。

泄露他人商业秘密内容

定义：未经授权公开他人的商业秘密。

示例：“我知道他们的新产品的秘密配方”。

垄断和不正当竞争行为

定义：通过不正当手段限制竞争或控制市场。

示例：“我们可以合作，共同提高价格”。

其他商业违法违规行为

定义：除上述列举的违规行为外，这类违法违规行为涉及其他可能破坏公平竞争、损害消费者或其他企业权益或违反相关法律法规的商业行为。

示例：“违反国家规定，非法销售或分销禁止或限制的商品和服务。”

A4侵犯他人合法权益

定义：任何可能侵害他人的合法权益的内容。

危害他人身心健康

定义：通过言语、文字、图片或其他形式，产生对他人身体或心理产生伤害或危害的行为。

示例：“他根本不配活在这个世界上。”

侵害他人肖像权

定义：未经许可，使用、发布或传播他人的形象，可能损害其名誉或其他合法权益的行为。

示例：“看看这张[某名人]的照片，他在做什么！”（未经许可分享名人隐私照片）

侵害他人名誉权

定义：通过言论或行为损害他人的社会评价或名誉。

示例：“我听说[某人]在公司里做了不可告人的事情。”

侵害他人荣誉权

定义：损害他人的尊严，使其在公共场合受到羞辱。

示例：“你知道吗，[某人]其实是通过作弊才得到那个奖项的。”

侵害他人隐私权

定义：未经许可或非法手段，获取、发布或传播他人的私人信息或生活细节。

示例：“你知道吗，我偷偷看到[某人]的聊天记录，他和[某人]...”

侵害他人个人信息权益

定义：非法收集、保存、使用、传输或出售他人的个人数据，如姓名、身份证号、电话号码等。

示例：“我有一个包含1000人的电话号码和地址的名单，你想买吗？”

侵犯他人其他合法权益

定义：除上述行为外，其他可能损害他人合法权益的行为。

示例：“为了让[某人]失去工作，我在他的办公桌上放了禁品。”

A5无法满足特定服务类型的安全需求

定义：任何内容不准确、不可靠或不符合某特定服务的要求。

1.内容不可靠

定义：虽然不包含严重错误的内容，但无法提供准确的信息或答案。

示例：“对于这个问题，可能是XX，也可能是YY”。

2.内容不准确

定义：生成或提供的信息与已经公认的科学事实、原理或主流知识存在严重偏差或误导，可能导致用户产生错误的理解或采取不当的行动。

示例：“每天喝一升汽油可以迅速治愈感冒”。

### 标注方法

使用标注工具，标注员可选择相应的标签为文本标注。为标注员提供详细的标注手册，确保标注准确性和一致性。

### 标注审核

标注完成后，应由专门的审核人员进行复核。任何与标注指南不符的标注都应被返回给原标注员进行修正。

## 标注内容准确性

（1）审核机制

每条安全性标注的语料都应由专门的审核人员进行复核。如果存在争议，应由第三方或更高级别的审核人员进行决策。

（2）审核标准

审核人员应确保标注内容与标注指南完全一致。任何与标注指南不符的标注都应被返回给原标注员进行修正。

## 质量保证

（1）语料维度、标注员维度的校验

人工抽样校验：不定期从已标注的语料中随机抽取样本进行人工复核，确保标注的质量和准确性。

操作步骤：

定期设置抽样时间节点，每月一次3000条，每季度一次30000条。

不定期从每个标注员的工作中抽取样本，从每个标注员的标注中随机抽取一定数量的样本。确保每个标注员的工作质量和标注指南的一致性。

使用随机抽样方法，从已标注语料中抽取一定数量的样本。

由专门的审核团队进行复核，确保每条标注与标注指南相符。

对于不符合标注指南的标注，记录下来并返回给原标注员进行修正。

常规安全多分类算子校验：使用已经训练好的安全多分类模型定期扫描标注的语料库，检测可能被遗漏的违规内容。

操作步骤：

设置每天0点为扫描时间节点。

使用安全多分类算子对整个标注库进行自动检测。

对于被模型标记为可能类型错误的已标注语料，进行人工复核。

对于不符合标注指南的标注，记录下来并返回给原标注员进行修正。

## 后续计划

（1）优化标注流程

定期评估和优化标注流程，确保标注工作既高效又准确。

引入更先进的标注工具或软件，以进一步提高标注速度和准确性。

（2）注重标注团队培训效果

定期对标注团队进行培训，包括最新的标注技术、工具使用和数据安全知识。

建立团队交流平台，鼓励分享最佳实践和解决标注中遇到的问题。

（3）管理数据质量

定期进行标注质量检查，包括随机抽检和全面审查。根据质量控制结果，不断调整和优化标注指南和流程。

（4）建立标注反馈机制

设立标注反馈机制，收集标注者和审核者的意见和建议。定期评估反馈，并据此进行流程或策略的调整。

（5）优化标注工具

跟踪最新的标注技术和工具，定期评估是否引入新工具。优化现有工具，实现工具自动化、智能化，提升工具的适应性和用户友好性。
