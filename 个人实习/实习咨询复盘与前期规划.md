# 个人实习方向思考与前期规划

> **主题**：不急着买服务，也不急着定岗位；先用项目和实习验证方向，再决定是否为求职服务付费。

## 一、现状与定位

- **毕业时间**：2028 年 6 月
- **背景**：Data Science + NLP（计算语言学）
- **定位**：半技术 + 半管理 / 半业务，不想纯 coding
- **阶段目标**：2027 年 2–4 月投暑期实习并争取转正，2027 年下半年主攻秋招

## 二、校招时间线

| 阶段 | 时间 | 事项 |
| --- | --- | --- |
| 暑期实习 | 2027 年 2–4 月 | 投递暑期实习，争取转正 |
| 秋招提前批 | 2027 年 6–8 月 | 投递提前批岗位 |

## 三、真正要解决的问题

咨询顾问推荐什么岗位，其实不是最关键的。真正重要的是：

> **2027 年 2 月之前，能不能拿出东西去投？**

### 准备节奏

| 时间 | 要完成的事 |
| --- | --- |
| 现在 → 2026 年底 | Python / SQL / Excel / 数据分析基础 |
| 2026 年底 → 2027 年初 | 2–3 个能拿得出手的项目 |
| 2027 年初 | 简历 + LeetCode / 笔试基础 + SQL 面试 + 行测 / 业务面试 |
| 2027 年 2–4 月 | 开始投实习 |

这才是现在真正应该解决的问题。

## 四、对岗位方向的判断

顾问推荐了三个方向：产品经理、商业分析、咨询行业。不会因为 84,800 元贵，就把这些建议全部否定，但三个方向要拆开看。

### 产品经理：更适合 AI Product Manager

这个方向适合的能力组合是：

> 技术理解 + 用户需求 + 产品设计 + 沟通

结合 Data Science + NLP 背景，优先考虑 **AI Product Manager**，而不是传统互联网产品经理。

### 商业分析：值得重点考虑

它要求的是：

> 数据分析 + SQL + Excel + Python + Business Sense + Presentation

而不是要求：

> Python 写得像计算机科班大神。

可以进一步发展成：

> **Data / Business Analyst → Senior Analyst → Strategy / AI / Business roles**

这比较符合“不想纯 coding”的路线。

### 咨询：先分清“什么咨询”

顾问的说法是：乙方宽泛而多元，发展上限好，但工作压力和学习压力大。这个逻辑成立，但“咨询”本身太泛：

- 战略咨询
- 管理咨询
- IT 咨询
- 数据咨询
- AI 咨询
- 数字化咨询

它们完全不是一个东西。以个人背景，重点看 **数字化咨询 / AI 咨询 / 数据咨询 / IT 咨询**，而不是泛泛地去投战略咨询。

### 甲方 vs 乙方

| 维度 | 乙方咨询机构 | 甲方企业 |
| --- | --- | --- |
| 工作内容 | 宽泛而多元 | 狭窄而深入 |
| 发展上限 | 非常好 | 受岗位方向限制，换方向 / 跳槽困难 |
| 工作稳定性 | — | 长期稳定 |
| 压力 | 工作压力、学习压力都较大 | — |

## 五、对机构服务的判断

### 对方提供的实习项目

- 线上实训项目：1 个月
- 字节跳动 · 商业分析
- 线上人事实习：2 个月
- 微软 · 产品经理

### 对方提供的全流程求职服务

1. **简历与求职材料**：撰写简历，准备多版本中英文双语简历。
2. **人岗匹配与内推**：精准匹配岗位，提供企业资源内推、简历代投。
3. **通用笔面试辅导**：人事服务老师、人事笔面试、基础笔面试、行测。
4. **专业笔面试辅导**：行业通识、专业笔面试。
5. **Offer 筛选与谈薪**。

**交付标准**：找到满意的工作并成功入职。

### 必须核实的问题

签约或付费前，要向机构逐条确认：

- [ ] 这个实习项目的法律 / 招聘主体是谁？
- [ ] 本人是否为微软正式员工 / 实习生？
- [ ] 是否有微软官方 HR、实习证明、劳动 / 实习协议？
- [ ] 项目是在微软真实业务环境中进行，还是培训机构自己设计的模拟项目？

如果是后者，那么它本质上就是：

> **培训项目 / 模拟实训**

而不是可以毫无顾虑写进简历的：

> **Microsoft — Product Manager Intern**

这个区别非常大。

### 价格判断

对方报价 84,800 元。**先别买。** 这个价格到底解决了什么问题，要等完成下面的验证再判断。

## 六、方向验证方式：用实习来测试

暂时不决定“产品经理 vs 商业分析 vs 咨询”，因为有一个很好的条件：

> **可以用实习来测试。**

比如：

**第一段：商业分析 / Data Analyst**

↓ 发现：

> “喜欢分析业务，但不喜欢天天做报表。”

**第二段：AI Product / AI Solution**

↓ 发现：

> “喜欢和业务、客户、技术团队沟通。”

那么最终定位就可能变成：

> **AI Product / AI Solution / AI Consultant**

这比坐在宿舍里空想“到底适合哪个”，有效得多。

## 七、低成本验证计划

接下来 1–2 个月，先不付费，把这次咨询得到的信息变成一个实验，验证三个方向：

| 方向 | 验证方式 |
| --- | --- |
| 商业分析 | 做一个完整的 Business / Data Analysis 项目 |
| AI 产品 | 做一个 AI 产品原型 / PRD |
| AI / 咨询 | 做一个真实业务问题的 AI / Data Solution |

然后看：

> **自己到底更喜欢哪个？**

同时开始看真实招聘 JD，慢慢弄清楚：

> “商业分析到底需要什么？”

> “AI PM 到底需要什么？”

> “咨询到底在招什么？”

到那个时候，再回头看 **84,800 元的服务到底解决了什么问题**，判断会清楚很多。
